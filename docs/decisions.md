# 디스코프 트리거·플랜 B 발동 기록

디스코프 트리거(T1/T2) 또는 플랜 B가 발동될 때마다 아래 형식으로 한 건씩 기록한다.

## 트리거 정의

- **T1 (기능 보호)**: P4 진입 시점에 M2(1일차 MVP 완주)가 미완결인 경우 → `Data/scenarios.csv`의 `special` 열을 일괄 `none`으로 변경(3일차 특수 요청 제외).
- **T2 (에셋 보호)**: 특정 상품의 `retake_count > 2`(총 3회 촬영) 후에도 품질 기준 미달인 경우 → `Data/products.csv` 해당 행 `status=dropped` 전환 후 실물 상품 종목 대체.
- **플랜 B**: 게이트 판정 No-go 시 사전 정의된 대체 경로 발동(예: Scaniverse 단일 경로 + Colab 학습).

## 기록 형식

발동 건마다 아래 4항목을 반드시 채운다.

```
### [YYYY-MM-DD] <T1|T2|플랜 B> 발동
- 일시:
- 사유:
- 영향 범위:
- 판단·2인 합의:
```
