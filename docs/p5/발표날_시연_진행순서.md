## 연결 방법: 케이블을 기본으로, 무선(Air Link)은 덤으로

**집에서는 지금까지 케이블 없이 Air Link(와이파이 무선)로 연결했다**(PC의 Link 서비스 기록 11/11~11/15). 헤드셋 성능 숫자도 Air Link로 잰 것이다. 하지만 Air Link는 PC와 헤드셋이 **같은 공유기(같은 네트워크)**에 붙어 있어야 서로를 찾는다. 실습실 PC는 학교 유선망, 헤드셋은 학교 와이파이에 붙게 되는데, 학교망은 둘이 서로를 못 찾게 막혀 있는 경우가 많고 학번 로그인 와이파이는 헤드셋을 붙이기도 어렵다. 실습실 데스크톱은 보통 와이파이가 없어 휴대폰 핫스팟으로 묶을 수도 없다. **그래서 당일은 USB 케이블로 연결한다.**

| 순위 | 연결 | 준비 | 메모 |
|---|---|---|---|
| 1 | **USB 3 케이블**(5Gbps 이상) | 헤드셋 쪽 USB-C, PC 쪽은 USB-A(일반 USB)가 무난. USB-C 케이블이면 USB-A 변환 젠더도 함께. 길이 2~3m 이상 | 포장에 "USB 3.0" 또는 "데이터 5Gbps" 표시를 본다. 싼 충전 전용·USB 2.0 케이블은 화질이 떨어지거나 안 될 수 있다 |
| 2 | Quest 2 상자의 **충전 케이블**(양쪽 USB-C, 약 1m) | 실습실 PC에 USB-C 포트가 있어야 한다 | USB 2.0 속도라 화질이 조금 떨어지고 짧다. 그래도 된다 |
| 3 | **Air Link**(무선) | 실습실 PC와 같은 네트워크에 붙는 와이파이가 있어야 한다(조교에게 문의) | 집에서 쓰던 방식. 헤드셋 빠른 설정 > Link에서 무선으로 켜고 PC를 고른다. Link 앱 설정에서 Air Link가 켜져 있어야 한다 |

- 새 케이블은 **발표 전에 집 PC에서 한 번 시험**한다: Link 앱 > 기기에서 헤드셋이 연결됨으로 뜨는지(USB 연결 테스트), `2_start_demo.bat`으로 켠 게임이 헤드셋에 뜨는지. 케이블로 켜 본 적은 아직 없다.

## 가. 실습실 PC 준비

가져갈 것: `DongA_Store_Demo.zip`(USB와 구글 드라이브 둘 다), **USB 3 케이블(USB-C ↔ USB-A, 2~3m)과 변환 젠더, Quest 2 충전 케이블(예비)**, 충전한 헤드셋, 맥북(슬라이드), Meta 계정 비밀번호(직접 입력).

1. 압축을 실습실 PC의 바탕화면 같은 곳에 **풀어서** 쓴다(USB에서 바로 켜지 않는다).
2. **`1_check_pc.bat` 더블클릭**: 그래픽카드·메모리·USB 3·Link 앱·OpenXR 런타임·관리자 권한을 보고 `check_result_<PC이름>_<시각>.txt`로 남긴다. 아무것도 바꾸지 않는다.
3. Link 앱이 없으면 설치한다: USB에 받아 둔(없으면 meta.com에서) Windows용 **Meta Quest Link 앱** 설치 파일로 설치 → 헤드셋과 같은 Meta 계정으로 로그인 → 기기 추가에서 Quest 2, 연결 방식은 Link(케이블). 케이블을 꽂으면 헤드셋에 Link를 켤지, 데이터 접근을 허용할지 묻는 창이 뜰 수 있다: 켜기·허용. 관리자 권한이 필요하다. 설치 파일(약 5MB)은 내려받기 도구라서 설치하면서 인터넷으로 나머지(1GB 안팎, Meta가 밝힌 숫자는 아님)를 받는다. 오프라인 설치 파일은 없다. 권한이 없으면 조교에게 부탁한다.
4. Link 앱 **설정 > 일반**: **알 수 없는 출처**를 켠다. **OpenXR 런타임**이 Meta Horizon Link인지 본다(SteamVR이 잡고 있으면 바꾼다. `1_check_pc.bat`이 [고칠것]으로 알려 준다).
5. 그래픽카드가 [빠듯]이면 Link 앱 **기기 > Quest 2 > 그래픽 환경설정**에서 주사율 72Hz, 렌더 해상도를 한 단계 낮춘다.
6. 실습실 PC는 다시 켜면 설치한 것이 사라질 수 있다. 설치한 뒤에는 **재부팅하지 않는다**.

## 1. 플랜 A: 헤드셋으로 켜는 순서

1. PC에서 **Meta Horizon Link 앱**을 켜고, 헤드셋을 케이블로 연결한다(USB 3 포트: 파란색 USB-A 또는 USB-C. 케이블이 안 되면 위 표의 2·3번).
2. 진행자가 **헤드셋을 쓰고 Link 홈(하얀 배경)이 보이는지** 확인한다. 안 보이면 헤드셋의 빠른 설정에서 Link를 켠다. 헤드셋 라이브러리의 "VRStore"는 **누르지 않는다**(옛 측정 모드가 켜진다).
3. 헤드셋을 쓴 채로(또는 체험자에게 씌운 채로) PC에서 **`2_start_demo.bat` 더블클릭**.
   - "Link가 켜져 있지 않습니다"가 뜨면 N을 누르고 1번부터 다시.
   - "이미 켜져 있습니다"가 뜨면 새로 켤 필요 없다. 아래 4번으로.
4. 헤드셋에 매장이 보이면 체험자를 편한 자리에 세우고, **PC의 게임 창을 한 번 누른 뒤 F5**. 그 자리가 계산대 안쪽 점원 자리가 된다.
5. 튜토리얼 여섯 단계 → 손님 3명(카드·봉투, 현금, 현금·봉투) → 정산판. 해 본 사람 기준 약 3분이다.
6. 다음 사람: 헤드셋을 넘기고 **게임 창을 누르고 F5**(처음부터). 자리만 어긋났으면 **F6**. 키가 안 먹으면 게임 창을 한 번 누르고 다시.

## 2. 플랜 B-2: 키보드·마우스 조작 (`4_pc_keyboard.bat`)

헤드셋 대신 모의 컨트롤러(XR Device Simulator)로 움직인다. 게임 창을 한 번 누른 뒤:

| 하고 싶은 것 | 키 |
|---|---|
| 고개 돌리기 | 마우스 **오른쪽 버튼을 누른 채** 움직이기 |
| 오른손 잡기 / 왼손 잡기 | **Y** / **T** (다시 누르면 놓음), Esc는 손 조작 끝내기 |
| 잡은 손 옮기기 | 마우스 이동(좌우·위아래), **휠**(앞뒤) |
| 손 돌리기(바코드 찾기) | **R**로 옮기기↔돌리기 전환 |
| 물건 쥐기·놓기 | **G**(쥐기, 누른 동안 쥠) |
| 방아쇠(버튼 누르기) | 마우스 **왼쪽** |
| 손 위치 되돌리기 | **V** |
| 처음부터 / 계산대 자리로 | **F5** / **F6** |

조작이 어색하니 조교에게는 B-1(자동 플레이)을 먼저 보여 드리고, 진행자가 직접 이 조작으로 상품 하나를 집어 스캔하는 정도를 보여 드린다.

## 3. 안 될 때

| 이렇게 되면 | 이렇게 한다 |
|---|---|
| 헤드셋에 게임이 안 뜨고 PC 창에서만 돈다 | 게임 창을 닫는다 → 헤드셋을 쓰고 Link 홈 확인 → 다시 더블클릭. 그래도 안 되면 가-4(알 수 없는 출처, OpenXR 런타임) |
| Link 앱이 헤드셋을 못 찾는다 | 케이블을 PC 뒷면의 다른 USB 3 포트에 꽂는다 → 헤드셋에서 허용 창 확인 → 그래도 안 되면 충전 케이블(USB-C 포트) → Air Link(같은 네트워크일 때만) |
| 게임이 스스로 꺼졌다 | Link가 끊긴 것이다(헤드셋을 오래 벗어 두거나 케이블이 빠지면 난다). Link 다시 연결 → Link 홈 확인 → 다시 더블클릭 |
| 헤드셋을 잠깐 벗었다 썼더니 손님이 카드 없이 나갔다 | 벗은 동안에도 게임 시간은 흐른다(카드는 5초 안에 돌려줘야 한다). 그대로 진행하거나 F5 |
| 화면이 뚝뚝 끊긴다 | 가-5처럼 Link 앱에서 렌더 해상도를 낮추고 다시 켠다 |
| 시점이 갑자기 높아졌다 | F6, 그래도 이상하면 F5 |
| 화면이 멈추거나 이상하다 | 게임 창을 닫고 다시 더블클릭 |
| 헤드셋이 끝내 안 된다 | **플랜 B**: `3_pc_autoplay.bat`, 이어서 `4_pc_keyboard.bat` |
