# 발표 날 시연 진행 순서 (한 장, 2026-11-17)

> 진행하는 사람이 보고 따라 하는 순서. 게임은 Windows PC에서 켜고, 체험하는 사람은 헤드셋만 쓴다.
> 발표 날에는 **학교 실습실 Windows 데스크톱**을 쓴다(맥북은 Link가 안 돼서 슬라이드용).
> 실행 파일: 저장소에서는 맨 위의 `시연모드_켜기.bat`, 실습실 PC 묶음(`DongA_Store_Demo.zip`)에서는 `2_start_demo.bat`. 둘은 같은 파일이다. 게임 `Builds/Store/VRStore.exe`를 시연 모드(`-demo`)로 켠다.

## 가. 실습실 PC 준비 (가능하면 11/16에 미리, 늦어도 발표 1시간 전)

가져갈 것: `DongA_Store_Demo.zip`(USB 또는 구글 드라이브), **Link 케이블**, 충전한 헤드셋, 맥북(슬라이드·영상).

1. 압축 파일을 실습실 PC의 바탕화면 같은 곳에 **풀어서** 쓴다(USB에서 바로 켜지 않는다).
2. **`1_check_pc.bat` 더블클릭**: 그래픽카드·메모리·USB 3·Link 앱·OpenXR 런타임·관리자 권한을 보고 `check_result_<PC이름>_<시각>.txt`로 남긴다. 아무것도 바꾸지 않는다.
   - [부족]이나 [위험]이 나오면 헤드셋 체험은 어렵다. 영상으로 대신할 준비를 한다.
3. Link 앱이 없으면 설치한다: meta.com에서 Windows용 **Meta Quest Link 앱**을 받아 설치 → 헤드셋과 같은 Meta 계정으로 로그인 → 기기 추가에서 Quest 2, 연결 방식은 Link(케이블). 관리자 권한이 필요하고 수 GB를 받는다(인터넷 필요, 수십 분 걸릴 수 있다). 권한이 없으면 조교에게 부탁한다.
4. Link 앱 **설정 > 일반**:
   - **알 수 없는 출처**를 켠다(스토어 밖 게임이라 꺼져 있으면 헤드셋에 안 뜰 수 있다).
   - **OpenXR 런타임**이 Meta Horizon Link인지 본다. SteamVR이 잡고 있으면 바꾼다(`1_check_pc.bat`이 [고칠것]으로 알려 준다).
5. 그래픽카드가 [빠듯]이면 Link 앱 **기기 > Quest 2 > 그래픽 환경설정**에서 주사율 72Hz, 렌더 해상도를 한 단계 낮춘다.
6. 아래 1장 순서대로 한 판을 해 본다. 미리 해 봤다면 그 PC에서 **다시 시작(재부팅)하지 않는다**. 복원 프로그램이 깔린 실습실 PC는 다시 켜면 설치한 Link 앱이 사라질 수 있다.

## 0. 발표 전에 (그날 아침)

- [ ] 헤드셋 충전, Link 케이블.
- [ ] `시연모드_켜기.bat`(묶음에서는 `2_start_demo.bat`)으로 한 번 켜서 **게임 창을 누르고 F5**를 눌러 본다. 처음부터 다시 시작하면 정상이다(이 키는 아직 헤드셋을 쓴 채로 눌러 본 적이 없다).
- [ ] 틀 영상을 맥북에서 미리 열어 소리까지 나는지 본다: `capture/film/presentation_v5.mp4`(100초, 슬라이드 3번 장의 `assets/demo.mp4`와 같다).

## 1. 켜는 순서

1. PC에서 **Meta Horizon Link 앱**을 켜고, 헤드셋을 케이블로 연결한다(USB 3 포트: 파란색 USB-A 또는 USB-C).
2. 진행자가 **헤드셋을 쓰고 Link 홈(하얀 배경)이 보이는지** 확인한다. 안 보이면 헤드셋의 빠른 설정에서 Link를 켠다. 헤드셋 라이브러리의 "VRStore"는 **누르지 않는다**(옛 측정 모드가 켜진다).
3. 헤드셋을 쓴 채로(또는 바로 벗어서 체험자에게 씌운 채로) PC에서 **실행 파일을 더블클릭**한다.
   - "Link가 켜져 있지 않습니다"가 뜨면 N을 누르고 1번부터 다시.
   - "이미 켜져 있습니다"가 뜨면 새로 켤 필요 없다. 아래 4번으로.
4. 헤드셋에 매장이 보이면 체험자를 편한 자리에 세우고, **PC의 게임 창을 한 번 누른 뒤 F5**. 그 자리가 계산대 안쪽 점원 자리가 된다.
5. 튜토리얼 여섯 단계 → 손님 3명(카드·봉투, 현금, 현금·봉투) → 정산판. 해 본 사람 기준 약 3분이다.

## 2. 다음 사람에게 넘길 때

- 헤드셋을 넘기고, 새 사람이 자리를 잡으면 **게임 창을 누르고 F5** (처음부터 다시).
- 시작한 뒤 자리만 어긋났으면(계산대가 너무 멀거나 옆에 있으면) **F6** (자리만 다시 맞춤, 진행은 그대로).
- 키가 안 먹으면 게임 창이 앞에 있지 않은 것이다. 헤드셋을 쓰면 Link 창이 앞으로 올 수 있다. 게임 창을 한 번 누르고 다시 누른다.

## 3. 안 될 때

| 이렇게 되면 | 이렇게 한다 |
|---|---|
| 헤드셋에 게임이 안 뜨고 PC 창에서만 돈다 | 게임 창을 닫는다 → 헤드셋을 쓰고 Link 홈(하얀 배경) 확인 → 다시 더블클릭. 그래도 안 되면 가-4(알 수 없는 출처, OpenXR 런타임) |
| 게임이 스스로 꺼졌다 | Link가 끊긴 것이다(헤드셋을 오래 벗어 두거나 케이블이 빠지면 난다). Link 다시 연결 → 헤드셋에서 Link 홈 확인 → 다시 더블클릭 |
| 헤드셋을 잠깐 벗었다 썼더니 손님이 카드 없이 나갔다 | 헤드셋을 벗은 동안에도 게임 시간은 흐른다(카드는 5초 안에 돌려줘야 한다). 그대로 진행하거나 F5 |
| 화면이 뚝뚝 끊긴다 | 가-5처럼 Link 앱에서 렌더 해상도를 낮추고 다시 켠다 |
| 시점이 갑자기 높아졌다 | F6, 그래도 이상하면 F5. 나중에 원인을 보게 로그 이름을 적어 둔다 |
| 화면이 멈추거나 이상하다 | 게임 창을 닫고 다시 더블클릭 |
| 5분 안에 살아나지 않는다 | **영상으로 대신한다**: 맥북의 `presentation_v5.mp4` |

## 4. 끝나고

- 로그는 켤 때마다 실행 파일 옆 `capture/demo_logs/demo_날짜_시각.log`로 따로 남는다. 이상한 일이 있었으면 시각만 적어 두면 나중에 찾을 수 있다(`[Body]` 줄은 높이, `[Customers]` 줄은 손님 계산).
- 게임은 창을 닫아 끈다. 실습실 PC에 남긴 압축 푼 폴더와 로그는 필요하면 USB로 가져온다.
