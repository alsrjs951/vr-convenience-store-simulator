# 발표 날 시연 진행 순서 (한 장, 2026-11-17)

> 진행하는 사람이 보고 따라 하는 순서. 게임은 PC에서 켜고, 체험하는 사람은 헤드셋만 쓴다.
> 실행 파일: 저장소 맨 위의 **`시연모드_켜기.bat`** (더블클릭). 게임은 `Builds/Store/VRStore.exe`를 시연 모드(`-demo`)로 켠다.

## 0. 발표 전에 (전날 또는 그날 아침)

- [ ] 발표장(또는 쓸 PC)에서 Link 케이블·Meta Horizon Link 앱이 붙는지 본다. 헤드셋 충전.
- [ ] `시연모드_켜기.bat`으로 한 번 켜서 **게임 창을 누르고 F5**를 눌러 본다. 처음부터 다시 시작하면 정상이다(이 키는 아직 헤드셋을 쓴 채로 눌러 본 적이 없다).
- [ ] 틀 영상을 미리 열어 소리까지 나는지 본다: `capture/film/presentation_v5.mp4` (100초, 슬라이드 3번 장의 영상과 같다).

## 1. 켜는 순서

1. PC에서 **Meta Horizon Link 앱**을 켜고, 헤드셋을 케이블로 연결한다.
2. 진행자가 **헤드셋을 쓰고 Link 홈(하얀 배경)이 보이는지** 확인한다. 헤드셋 라이브러리의 "VRStore"는 **누르지 않는다**(옛 측정 모드가 켜진다).
3. 헤드셋을 쓴 채로(또는 바로 벗어서 체험자에게 씌운 채로) PC에서 **`시연모드_켜기.bat`을 더블클릭**한다.
   - "Link가 켜져 있지 않습니다"가 뜨면 N을 누르고 1번부터 다시.
   - "이미 켜져 있습니다"가 뜨면 새로 켤 필요 없다. 아래 4번으로.
4. 헤드셋에 매장이 보이면 체험자를 편한 자리에 세우고, **PC의 게임 창을 한 번 누른 뒤 F5**. 그 자리가 계산대 안쪽 점원 자리가 된다.
5. 튜토리얼 여섯 단계 → 손님 3명(카드·봉투, 현금, 현금·봉투) → 정산판. 해 본 사람 기준 약 3분이다.

## 2. 다음 사람에게 넘길 때

- 헤드셋을 넘기고, 새 사람이 자리를 잡으면 **게임 창을 누르고 F5** (처음부터 다시).
- 시작한 뒤 자리만 어긋났으면(계산대가 너무 멀거나 옆에 있으면) **F6** (자리만 다시 맞춤, 진행은 그대로).
- 키가 안 먹으면 게임 창이 앞에 있지 않은 것이다. 헤드셋을 쓰면 Link 창이 앞으로 올 수 있다. 게임 창을 한 번 누르고 다시 누른다.

## 3. 안 될 때

| 이렇게 되면 | 이렇게 한다 |
|---|---|
| 헤드셋에 게임이 안 뜨고 PC 창에서만 돈다 | 게임 창을 닫는다 → 헤드셋을 쓰고 Link 홈(하얀 배경) 확인 → 다시 더블클릭 |
| 게임이 스스로 꺼졌다 | Link가 끊긴 것이다(헤드셋을 오래 벗어 두거나 케이블이 빠지면 난다). Link 다시 연결 → 헤드셋에서 Link 홈 확인 → 다시 더블클릭 |
| 헤드셋을 잠깐 벗었다 썼더니 손님이 카드 없이 나갔다 | 헤드셋을 벗은 동안에도 게임 시간은 흐른다(카드는 5초 안에 돌려줘야 한다). 그대로 진행하거나 F5 |
| 시점이 갑자기 높아졌다 | F6, 그래도 이상하면 F5. 나중에 원인을 보게 로그 이름을 적어 둔다 |
| 화면이 멈추거나 이상하다 | 게임 창을 닫고 다시 더블클릭 |
| 5분 안에 살아나지 않는다 | **영상으로 대신한다**: `capture/film/presentation_v5.mp4` |
