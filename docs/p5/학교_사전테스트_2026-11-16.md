## 0. 출발 전

- [ ] USB에 `DongA_Store_Demo.zip`(0.6GB, PC의 `Builds\Package\`) 복사. 구글 드라이브에도 올리기
- [ ] USB에 `동아편의점_발표.pptx`(94MB, `docs\p5\slides\`) 복사
- [ ] 헤드셋 완전 충전
- [ ] **USB 3 케이블**(USB-C ↔ USB-A, 2~3m, 포장에 "USB 3.0" 또는 "5Gbps") + USB-C→A 변환 젠더. 못 구하면 Quest 2 충전 케이블이라도
- [ ] 맥북, 휴대폰(사진 기록), Meta 계정 비밀번호
- 참고: 집에서는 케이블 없이 **Air Link(무선)**로 해 왔다. 학교망에서는 무선이 서로를 못 찾을 가능성이 커서 케이블을 기본으로 한다.

## 1. 조교에게 먼저 물어보기 (5분)

- [ ] 데모 세션은 **어느 PC**에서 하나? (발표실 S06-603 PC인지, 따로 있는 실습실 PC인지) → 오늘 시험은 **그 PC로**
- [ ] **Meta Quest Link 앱**을 설치해도 되나? 관리자 권한이 필요하면 도움 부탁
- [ ] PC를 **다시 켜면 원래대로 돌아가나?** (그렇다면 발표 날 다시 설치해야 함)
- [ ] (선택) 그 PC와 같은 네트워크에 붙는 와이파이가 있나? (있으면 Air Link도 가능)

적어 둘 것: 데모 PC 위치 ________ / 설치 허용 ☐예 ☐아니오 / 재부팅 초기화 ☐예 ☐아니오

## 2. 발표실에서 PPT 영상 확인 (10분)

- [ ] 발표실 PC에서 USB의 PPTX 열기
- [ ] **8번 장(1분 시연 영상)** 슬라이드 쇼로 재생 → **소리까지** 나는가
- [ ] 14번 장(결과물 동영상)도 잠깐 재생
- [ ] 프로젝터에서 슬라이드가 잘리거나 글자가 너무 작지 않은가
- [ ] 안 되면: 맥북을 프로젝터에 연결해 보기(맥북으로 발표할 준비)

## 3. 데모 PC 사양 확인 (5분)

- [ ] 압축을 **바탕화면에 풀기** (USB에서 바로 켜지 않는다)
- [ ] `1_check_pc.bat` 더블클릭 → 결과 화면 **사진**, `check_result_….txt`를 USB로 복사
- [ ] 그래픽카드 판정: ☐좋음 ☐빠듯 → 4단계로 / ☐부족 → 헤드셋은 어려움, 6단계(플랜 B)만

적어 둘 것: 그래픽카드 ________ / 메모리 ____GB / USB 3 ☐있음 / Link 앱 ☐있음 ☐없음 / 관리자 ☐예 ☐아니오

## 4. Link 앱 준비 (0~30분)

- [ ] Link 앱이 이미 있으면 다음으로
- [ ] 없으면 meta.com에서 **Meta Quest Link 앱**(Windows용) 받아 설치(수 GB). 관리자 권한을 물으면 조교에게
- [ ] 헤드셋과 **같은 Meta 계정**으로 로그인 → 기기 추가 → Quest 2 → Link(케이블)
- [ ] Link 앱 **설정 > 일반**: **알 수 없는 출처** 켜기, **OpenXR 런타임**이 Meta Horizon Link인지 확인

적어 둘 것: 설치에 걸린 시간 ____분 (발표 날 다시 설치해야 할 수도 있다)

## 5. 헤드셋으로 게임 켜기: 플랜 A (15분)

- [ ] 케이블을 PC의 **USB 3 포트**(파란색 USB-A 또는 USB-C)에 꽂고 헤드셋에 연결
- [ ] 헤드셋 쓰기. 새 장소라 **경계(가디언) 설정**을 요구하면 **제자리 경계**로 빠르게
- [ ] Link를 켤지, 데이터 접근을 허용할지 묻는 창 → **켜기·허용**
- [ ] **Link 홈(하얀 배경)**이 보이는가
  - 안 보이면: 다른 USB 3 포트 → 충전 케이블(PC에 USB-C가 있을 때) → 같은 네트워크 와이파이가 있으면 Air Link
- [ ] 헤드셋 라이브러리의 "VRStore"는 **누르지 않는다** (옛 측정 모드)
- [ ] PC에서 `2_start_demo.bat` 더블클릭 ("Link가 켜져 있지 않습니다"가 뜨면 N, Link부터 다시)
- [ ] 헤드셋에 매장이 보이면 **게임 창을 한 번 누르고 F5** → 계산대 앞 점원 자리로 오는가
- [ ] **한 판 끝까지**: 튜토리얼 → 손님 3명 → 정산판. 시작 ____시 ____분 / 끝 ____시 ____분
- [ ] **F5**: 처음부터 다시 시작되는가 (헤드셋에서 처음 눌러 본다)
- [ ] **F6**: 자리만 다시 맞춰지는가
- [ ] 화면이 뚝뚝 끊기지 않는가. 끊기면 Link 앱 > 기기 > 그래픽 환경설정에서 렌더 해상도를 한 단계 낮추고 다시 켜기 (바꾼 값: ________)
- [ ] 점장·손님 목소리가 헤드셋에서 들리는가
- [ ] 게임 창을 닫아 끄기

이상한 장면은 휴대폰으로 찍고 시각을 적는다.

## 6. 플랜 B 확인 (10분, 헤드셋이 잘 됐어도 한 번씩)

- [ ] `3_pc_autoplay.bat`: PC 창에서 게임이 스스로 플레이하는가 (1~2분 보고 창을 닫아도 된다. 끝까지 두면 4~5분 뒤 저절로 닫힘)
- [ ] `4_pc_keyboard.bat`: 켜지는가, 마우스 오른쪽 버튼을 누른 채 움직이면 고개가 돌아가는가

## 7. 기록 챙기고 정리 (5분)

- [ ] 압축을 푼 폴더의 **`capture\demo_logs` 폴더 전체**를 USB로 복사 (헤드셋 연결, 시점 높이, 손님 계산 기록이 남아 있다)
- [ ] `check_result_….txt`도 USB로
- [ ] 오류 창·이상한 장면 사진
- [ ] 게임 폴더와 Link 앱은 **조교가 허락하면 그대로 두기** (발표 날 바로 쓸 수 있다)
- [ ] Meta 계정은 공용 PC이니 로그아웃해도 된다 (발표 날 다시 로그인 1분)

## 8. 결과에 따라 발표 날 할 일

| 오늘 결과 | 발표 날 |
|---|---|
| 헤드셋으로 한 판 성공 | 같은 순서로 켜기만 하면 된다(플랜 A). PC가 초기화되는 곳이면 Link 앱 설치 시간만큼 일찍 간다 |
