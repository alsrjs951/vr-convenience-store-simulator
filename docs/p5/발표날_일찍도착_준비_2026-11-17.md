## 3. 당일 시간표 (도착한 때부터)

두 사람이 일찍 오면 나눠서 한다: 한 사람은 데모 PC, 한 사람은 발표실 PPT 확인.

| 도착 후 | 할 것 | 막히면 |
|---|---|---|
| 0~10분 | 조교에게 데모 PC·설치 허용·재부팅 초기화를 확인(미리 답을 받았으면 생략). 그 PC 바탕화면에 USB의 zip을 복사해 **풀기** | |
| 10~15분 | `1_check_pc.bat` → 결과 화면 사진 | 그래픽카드 [부족] → 헤드셋은 포기, 플랜 B만 |
| 15분 | Link 앱이 없으면 USB의 설치 파일로 **설치부터 시작**(내려받는 동안 아래 일을 한다) | 권한 없음 → 조교에게. 끝내 안 되면 플랜 B |
| 15~25분 | `3_pc_autoplay.bat` → 1~2분 보고 창 닫기. 여기까지 되면 **플랜 B 확보** | 안 켜지면 `4_pc_keyboard.bat`도 해 보고, 화면 사진과 `capture\demo_logs`를 남긴다 |
| 15~30분 (동시에) | 발표실 PC에서 PPT 열고 **8번 장 영상이 소리까지** 나오는지, 14번 장도 잠깐 | 안 되면 맥북을 프로젝터에 연결해 발표 |
| 30~45분 | Link 앱에 헤드셋과 **같은 Meta 계정**으로 로그인 → 기기 추가(Quest 2, 케이블) → 설정 > 일반에서 **알 수 없는 출처** 켜기, **OpenXR 런타임**이 Meta Horizon Link인지 확인 → 케이블을 USB 3 포트에 꽂기 → 헤드셋에서 허용 → **Link 홈(하얀 배경)** | 다른 USB 3 포트 → 충전 케이블(USB-C 포트) |
| 45~60분 | `2_start_demo.bat` → 게임 창 누르고 **F5** → 한 판(약 3분) → F5·F6 한 번씩 | 끊기면 Link 앱에서 렌더 해상도 한 단계 낮추고 다시 켜기 |
| 60분~ | 게임 창을 닫는다. **PC를 다시 켜지 않는다.** 케이블은 꽂아 둔다 | |
| **14:30** | **결정**: 헤드셋으로 한 판이 됐으면 플랜 A, 아니면 플랜 B로 정하고 발표 준비 | |

- 헤드셋 라이브러리의 "VRStore"는 누르지 않는다. 게임은 늘 PC에서 bat으로 켠다.
- 새 장소라 헤드셋이 경계(가디언) 설정을 요구하면 **제자리 경계**로 빠르게 넘긴다.
