# 학습 PLY → Unity → Windows 실행 파일 검증

## 결과

- Nerfstudio splatfacto 150회 학습 결과를 UnityGaussianSplatting v1.1.0으로 변환했다. 입력·변환 에셋 모두 **12,970 splats**. [변환 기록](evidence/trained_import.txt).
- 별도 `Assets/Scenes/TrainedSplatTest.unity`에서 RTX 4070 / Direct3D12 렌더링 확인. 기존 `SplatTest`를 바탕으로 XR Origin, 시뮬레이터, 바닥을 유지했다.
- 에디터 및 Windows IL2CPP 실행 파일에서 합성 W 입력 → XR Device Simulator → 카메라 전진 확인. Transform 직접 이동을 사용하지 않는다. [에디터 기록](evidence/trained-editor/trained_runtime.txt), [실행 파일 기록](evidence/trained-player/trained_runtime.txt).
- 실제 프로젝트의 Windows x64 **Development IL2CPP** 빌드 성공. `TrainedSplatTest`(첫 씬)와 기존 `SplatTest` 포함. 최종 오류·경고·크기·시간은 [빌드 기록](evidence/project_il2cpp_build.txt) 참조.
- 화면을 직접 확인했다: [이동 전](evidence/trained-player/trained_before.png), [접근 후](evidence/trained-player/trained_after.png).

## 실행

`Builds/P0Windows/P0Simulator.exe`를 실행한다. 함께 생성된 `_Data`, DLL 등 **폴더 전체를 유지**해야 한다. 빌드 폴더는 Git 추적 대상이 아니다.

- 창을 클릭한 뒤 시뮬레이터 안내에 따라 WASD/QE 이동, 마우스 시점 회전.
- 화면의 `U`는 HMD 조작 모드 선택. 자동 검증 실행은 `-p0-verify -p0-evidence <절대 출력 폴더>` 옵션을 사용하며 약 7초 뒤 종료한다. 평상시 실행은 이 옵션 없이 한다.
- 에디터에서 `Assets/Scenes/TrainedSplatTest.unity`를 열어 Play해도 된다.
- 에셋/씬 준비 메뉴: `Tools > P0 > Import Trained Poster`. 기존 변환 에셋이 있으면 재사용하고 검증 씬을 재구성한다. 씬에 수동 변경을 했다면 실행 전에 별도 저장한다.
- 재빌드: Unity를 닫은 상태에서 Unity CLI의 `-batchmode -quit -projectPath <저장소> -executeMethod P0TrainedSplat.Build -logFile <로그>` 사용.

## 좌표와 품질

원본 카메라와 학습 시 저장된 dataparser 변환을 사용했다. 이미 적용된 전처리 변환을 중복 적용하지 않도록 제거하고, 시작 시점을 시뮬레이터 카메라에 맞췄다. OpenGL/Unity 좌표계 차이로 인한 좌우 반전은 별도 부모 Transform의 X 반사로 보정했다. **학습 좌표는 정규화된 값이며 실제 크기(m)가 검증된 것은 아니다.**

150회 학습은 파이프라인 동작 확인용이다. 의자·바닥·배경이 보이지만 흐림, 빈 부분, 떠 있는 스플랫이 남아 있다. 상품 라벨 가독성이나 최종 에셋 품질 통과를 의미하지 않는다. 데이터 출처·SHA256·재현 방법은 `Assets/GaussianSplats/Poster/README.md`에 기록했다.

## 제한 및 변경

- Quest 미연결/OpenXR 런타임 미설정 상태이므로 실행 로그에 `XR_ERROR_RUNTIME_UNAVAILABLE` 등 XR 초기화 실패가 남는다. 시뮬레이터 렌더·이동은 동작하지만 HMD 양안·72fps 검증은 미완료다.
- 이 빌드는 검증 씬 실행용이며 편의점 게임 기능 전체나 Release 성능 검증이 아니다.
- 빌드 과정에서 Unity가 URP 셰이더 사전 필터, 런타임 설정 목록, 기본 Volume Profile 등을 직렬화했다. Player 설정에는 Standalone IL2CPP 및 빌드에 필요한 preloaded asset 참조가 저장됐다.
- 자동 검증 코드는 `-p0-verify`가 있을 때만 입력을 주입하고 캡처·종료한다. 일반 실행에서는 동작하지 않는다.
