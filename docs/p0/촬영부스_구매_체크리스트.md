## 2. 수령 후 동작 확인

- [ ] 배경지: 조명을 켜고 구김·반사 반점이 없는 면인지 확인
- [ ] 조명: 최소~최대 밝기 조절 동작, 소프트박스 조립, 촬영 화면에 깜빡임(플리커) 없음 확인
- [ ] 스프레이: 실물 1개에 시험 분사 → 촬영 후 닦임/물세척으로 제거되는지 확인
- [ ] CPL: 폰에 클립 장착 → 화면을 보며 필터 회전에 따라 반사가 줄어드는지 확인
- [ ] 영수증·보증서 보관(파손·불량 시 교환용)

## 3. 촬영 규칙 요약 (구현 문서 3.2절 기준 — 매 상품 촬영 시 체크)

- [ ] 배경·조명: 무광 단색 배경지 + 균일 확산광(LED 소프트박스), 부스가 측면 주변광 반사를 차폐하는지 확인
- [ ] 카메라: 촬영 시작 전 노출(AE)·초점(AF)을 잠그고 촬영 내내 유지
- [ ] 궤도: 수평 2바퀴 — 눈높이 1바퀴 + 상방 45° 1바퀴
- [ ] 근접샷: 앞·뒤·양옆 근접 각 2장
- [ ] 바코드 면 필수 근접 촬영(게임 내 바코드 스캔 규칙용)
- [ ] 장수: 상품당 사진 100~150장, 반사 재질은 +30장
- [ ] 반사 재질(페트병·알루미늄 캔·유광 봉지): 무광 스프레이 도포 또는 CPL 장착으로 대응
- [ ] 소요 시간·조명 조건을 촬영 로그에 기록(구현 문서 3.8절 입력 항목)

## 4. 폰 준비 — P0-K2 스마트폰 부분

1. 폰의 앱 스토어에서 **Scaniverse**를 설치한다(iOS는 App Store, Android는 Google Play — Google Play 게시는 2026-10-25 확인), 첫 실행 시 카메라 권한을 허용한다.
2. 아무 물건 1개로 테스트 스캔 1회를 돌려 복원이 정상인지 확인한다.
3. 내보내기 동작 확인:
   - [ ] 스캔 결과의 공유/내보내기 메뉴에서 형식 목록을 확인한다
   - [ ] **SPZ** 항목이 있으면 SPZ로 1회 내보내기 → 파일 앱/공유 시트에서 실제 파일 저장까지 확인
   - [ ] SPZ가 목록에 없으면 **PLY**로 내보내기 → 저장까지 확인
   - 사용 가능 포맷 기록: ____________(SPZ / PLY 중 실제로 동작한 것)
4. 내보낸 파일은 `capture/products/{id}/scans/` 규칙(구현 문서 2장 — Git 제외 폴더)에 맞춰 폰→PC로 옮길 경로(파일 앱, 클라우드 등)를 정해둔다.

**병기 — Scaniverse를 쓰지 않는 경로(두 경로 모두 유효)**: 폰에서 Scaniverse 없이 **4K(60fps) 영상으로 상품을 촬영**해 원본을 남기고, 집 데스크톱(RTX 4070)에서 `splatfacto`로 학습해 PLY를 얻는 경로도 본 프로젝트의 정식 절차다(구현 문서 3.1절 S1 "4K 60fps 영상 프레임 추출", S2-2). Scaniverse 미설치·내보내기 실패여도 촬영 자체는 진행할 수 있다.

> 폰 외의 P0-K2 나머지 항목(macOS용 SuperSplat·Unity 6.3 LTS 설치)은 이 문서 범위 밖이며, 2026-10-25 기준 docs/p0 4개 문서 어디에도 별도 실행 지침이 없다(전수 확인). 최소 절차: **SuperSplat**은 마일스톤 140행 표기대로 로컬 실행 또는 브라우저 에디터 중 택일한다(브라우저 에디터는 설치 불요). **Unity 6.3 LTS**는 macOS에 Unity Hub를 설치한 뒤 `docs/p0/Unity_셋업_체크리스트.md` §1~2와 동일한 절차로 설치하되, macOS Metal 검수용(마일스톤 140행)이므로 Windows Build Support(IL2CPP) 모듈은 불요다. 설치한 형태·버전은 `docs/build_log.md`에 기록한다(P0-K4 규약).
