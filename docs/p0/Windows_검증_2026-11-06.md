## 재현 방법

1. Unity에서 `Tools → P0 → Add XR Rig to SplatTest` (`Ctrl+Shift+F8`). 씬을 저장한 뒤 실행한다.
2. 필요하면 편집 모드에서 `Reimport Sample Splat` (`Ctrl+Shift+F7`). 기존 PLY 변환기를 호출하며 1,200 splats인지 검사한다.
3. Play → Game 뷰 클릭. HMD 모드(U), WASD/QE 이동, 마우스 회전. UI의 현재 모드와 키 안내를 확인한다.
4. `Capture Play Evidence` (`Ctrl+Shift+F9`)로 `docs/p0/evidence/`에 화면·좌표 저장.
5. 자동 이동 검증은 새 Play 세션의 HMD 모드에서 `Test Simulator Movement` (`Ctrl+Shift+F10`). 임시 키보드 장치로 D를 약 0.5초 입력하고 제거한다. 이 검증은 카메라 위치를 바꾸므로 종료 후 Play를 다시 시작하면 초기화된다.
