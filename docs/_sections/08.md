## 8.5 디스코프 트리거 발동·기록 절차 (D5)

**T1 — MVP 3일 이상 지연 → 특수 요청을 3일차에서 제외.** W3 종료(11/15) 1일차 플레이(잡기→스캔→봉투·결제→정산+튜토리얼) 완주 불가 시 지연 개시, 11/18(수)에도 불완결이면 발동 → 시나리오 CSV `special` 일괄 `none`(§6.4, 코드 무변경), 3일차는 피크타임만으로 성립.

**T2 — 재촬영 2회 초과 → 목록 제외.** 상품 표 `retake_count`(§04)에 재촬영마다 +1, 3회 촬영 후에도 기준 미달 시 행 `status=dropped`·프리팹 제외. 보충 촬영 없음(15종은 상한, 진열 칸 축소) (제안 추가 — 재촬영 루프 차단, 분석 §3-E).

발동 즉시 `docs/decisions.md`에 일시·사유·범위 기록(팀장 판단·2인 합의) (제안 추가 — 발표용 리스크 근거).
