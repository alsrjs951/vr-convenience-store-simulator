# 3DGS 에셋 파이프라인 — 촬영→학습→정제→상품 표→자동 프리팹

소유자: 권도훈(S1~S4), S5 도구는 이민건(슬라이드 14). 상품 **15종 상한**, **재촬영 2회 초과 시 목록 제외**(D5). 브랜드 재현은 교내 과제 한정, 외부 공개 시 가상 라벨 교체(D6).

## 0. 6단계 개요 — 도구·입출력

| 단계 | 도구 | 입력 → 출력 |
|---|---|---|
| S1 촬영 | 스마트폰 | 상품 → 사진 100~150장/4K 영상(제안 추가) |
| S2-1 1차 학습 | Scaniverse(폰 완결) | 촬영본 → **SPZ** |
| S2-2 2차 학습 | splatfacto(Win NVIDIA GPU) | 사진 원본 → **PLY** |
| S3 정제 | SuperSplat(macOS) | SPZ/PLY → 정제본 **SPZ** |
| S4 상품 표 | 시트(macOS) | 실측·가격 → CSV 1행 |
| S5 자동 프리팹 | Unity 도구(Win) | SPZ + CSV 행 → 프리팹(§04) |

SPZ는 Scaniverse 출력, PLY는 splatfacto 출력(분석 §3-J 해소). Unity 반입물은 정제 후 **SPZ로 단일화**(제안 추가). 저장소 `capture/products/{id}/` 아래 `raw/`(git 미관리)·`scans/`·`cleaned/`를 두고 cleaned본만 `Assets/GaussianSplats/Products/{id}.spz`로 복사, `{id}`는 상품 표와 일치(제안 추가).

## 1. S1 촬영 체크리스트

- **배경·조명**: 단색 배경 + 균일 확산광, 노출·초점 잠금. 반사 재질은 부스로 측면 차폐(제안 추가 — 주변 반사 유입이 정제 난이도를 결정).
- **궤도(슬라이드 7)**: 수평 2바퀴(눈높이 + 상방 45°) 후 앞뒤·양옆 근접 각 2장, **바코드 면 필수 근접**(슬라이드 8의 게임 규칙).
- **장수**: 사진 100~150장, 반사 재질 +30장(제안 추가). 소요·조건은 로그 기록(§7 입력).

## 2. S2 학습 2단계 (D3)

1. **1차 Scaniverse(폰 완결)** — 전 상품 우선 처리.
2. **2차 splatfacto** — §6 판정에서 반사 재질 불량 시에만. Windows NVIDIA GPU에서 CUDA 필수(nerfstudio gsplat 백엔드 — 분석 §3-C). `ns-train splatfacto --data capture/products/{id}/raw` 후 `ns-export gaussian-splat`(제안 추가).
3. **플랜 B** — GPU 미확보 시 Scaniverse 단일 경로 + 학습만 Colab GPU 런타임(사진 업로드 → PLY 수령).

macOS는 학습 불가 → 환경표의 'macOS(3DGS 에셋)'을 **정제·데이터 관리**로 수정(분석 권고 4).

## 3. S3 정제 — SuperSplat(macOS)

불러오기 → 배경 컷아웃 → 플로터(떠다니는 점) 제거 → 실측 크기(cm) 입력으로 스케일 확정 → SPZ를 `cleaned/`에 내보내기. `scans/` 원본 보존. 수작업 예산 상품당 20~40분(제안 추가, W1 게이트 실측으로 보정).

## 4. S4 상품 표 기입

스키마는 §04. 여기서 채우는 값: `id`·`name`·`price`, 실측 3축, `barcode_face`(촬영 로그 대조), `retake_count`(제안 추가 — 3 초과 행은 프리팹 생성에서 제외해 디스코프 자동 실행), 정제 SPZ 경로. 15종은 무광 위주 + 반사 2~4종(제안 추가 — 최대 리스크 재질의 비중 제한).

## 5. S5 자동 프리팹 — 팀 인터페이스

입력 `cleaned/{id}.spz` + 상품 표 1행 → 출력 `Prefabs/Products/{id}.prefab`(4겹 구조·생성 로직은 §04). "상품 1종 추가 = 촬영 + 표 한 줄" 주장은 실제 절차로 수정(분석 권고 8): **촬영 → 학습 → 수동 정제 → 표 기입 → 자동 프리팹 → 진열대 재병합(§07)**. 자동화는 프리팹 생성뿐이다.

## 6. 품질 판정·재촬영 규칙 (게이트 기준 전체는 §09)

| 항목 | 합격 기준 |
|---|---|
| 형태 | 외곽 왜곡·파손 없음 |
| 인쇄 | 라벨 글씨·바코드 판독 가능(분석 권고 2) |
| 반사 | 표면 재질 식별 가능, 협광으로 라벨 가림 없음 |
| 잔여 | 정제 후 플로터·배경 잔여 없음 |

불합격 → 재촬영 **최대 2회**(조명·장수 조정), 초과 시 목록 제외(D5). 반사 재질은 1회 재촬영 후에도 불량이면 splatfacto 전환. W1 게이트 시험 3종 = 무광 1 + 페트병·캔 2(제안서 1주차 판정 항목 반영).

## 7. 상품당 시간 예산 실측 양식 (분석 권고 7)

| id | 촬영(분) | 학습 경로·소요(분) | 정제(분) | 재촬영 | 합계(시간) |
|---|---|---|---|---|---|

목표 상품당 총 1.5~2시간(제안 추가 — 15종 × 2시간 ≈ 30시간의 4주 배분 근거). W1 게이트에서 3종 실측 후 보정하고, 그 값으로 §08 일정의 15종 완주 여부를 판정한다.
