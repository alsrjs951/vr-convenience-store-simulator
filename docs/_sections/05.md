# VR 인터랙션 — 잡기·회전, 바코드 판정, 봉투·결제

소유자: 이민건(슬라이드 14). HMD: Quest 3 + Link/PCVR(기본값 D2). XR 리그·텔레포트는 §02, 프리팹 4겹은 §04, 근무 루프는 §06.

## 1. 씬 계층과 레이어

- XR Origin 리그 구성(Direct Interactor·Poke Interactor)은 §02. 계산대에 `ScannerZone`·`BagZone`·카드 단말기 슬롯·`CashDrawer`/`ChangeTray` 트리거(모두 isTrigger)와 POS 월드스페이스 캔버스.
- **레이어 매트릭스**는 `BarcodeFace×Scanner`, `Interactable×Bag/Drawer/Tray`만 허용(제안 추가 — 오탐 충돌 최소화). 오디오: '삑'·'띠르릉'·'철컥'·'땡' 4효과음(3D 공간음).

## 2. 잡기·회전·내려놓기 — 프록시 콜라이더 기준

3DGS에 충돌 정보가 없으므로(슬라이드 8) 상호작용은 전부 ② 프록시 BoxCollider에서 일어난다.

| 컴포넌트 | 설정 |
|---|---|
| Rigidbody | 무게 0.1~1.0kg, Interpolate, Continuous Dynamic |
| BoxCollider(②프록시) | 상품 표 실측 크기(cm) 그대로, Center=무게중심 |
| XR Grab Interactable | Velocity Tracking, Throw On Detach ON, Attach=무게중심, Select Mode: Single |
| 자식 ③BarcodeTrigger | isTrigger, 레이어 `BarcodeFace`, 면적 80%·바깥 2mm 돌출 |

- **잡기**: 그립 Select + 햅틱 0.3/0.05초(제안 추가 — 스캔 햅틱과 구분). **회전**: 손목 회전으로 바코드를 찾는다(슬라이드 3·11). 양손 동시 잡기는 여유 시 옵션(제안 추가). **놓기**: 그립 해제 → velocity tracking 자연 낙하, 스냅 유인 없음(실재감 우선).

## 3. 바코드 판정 — '바코드 찾기가 곧 게임 규칙'

몸통 콜라이더는 무반응, `BarcodeFace` 트리거만 `Scanner`와 충돌 시 인식한다(슬라이드 8).

```csharp
// OnTriggerEnter(c) — 레이어 매트릭스로 BarcodeFace만 배치됨
var item = c.GetComponentInParent<ProductData>(); // ④ 데이터(id,name,price)
if (Time.time - lastScan < 0.5f) return;          // 재진입 쿨타임(제안 추가)
order.AddItem(item.id);                           // 동일 id는 수량+1, POS·HUD 갱신
audio.Play("beep"); light.Flash(); haptic.Send(0.6);
```

- 판정은 충돌만으로(속도·자세 조건 없음) — 난이도는 면 탐색 동작이 담당한다.
- **스캔 취소**: POS 목록 행을 트래시 존에 놓으면 1건 차감(제안 추가 — 실제 POS 관행의 오스캔 회복).

## 4. 봉투 담기 — 스플랫↔반투명 블렌딩 불량 대응

반투명 메시는 스플랫과 블렌딩 불량(공식 문서, 분석 §3-A) — alpha blend 비닐봉투는 담긴 상품과 뒤섞인다.

1. 봉투는 **URP Lit + Alpha Clipping(컷아웃)** 만 쓰고 반투명 패스 금지(제안 추가 — 공식 제약 직접 회피). 형태는 윗면이 트인 사다리꼴로 깊이 정렬 겹침을 최소화.
2. **담기 판정**: `BagZone` 진입 + 속도 0.5m/s 이하 0.3초 유지 → Bagged. 상품은 봉투로 페어런팅, Rigidbody·콜라이더 비활성, 스플랫 렌더러는 유지(주문 대조용).
3. 주문 HUD "봉투 필요" 손님은 봉투에, 미표기는 바구니 복귀(슬라이드 11).

## 5. 카드·현금 결제·거스름돈

'손님의 지불'은 캐릭터 없음(기본값 D4)에 따라 계산대 접시에 스폰되는 지폐 프리팹으로 표현한다(제안 추가 — D4의 보완). 지폐·동전도 §2 프리팹 규칙을 따름.

| 결제 | 절차 | 판정 |
|---|---|---|
| 카드 | HUD "카드 결제" → 카드 소품을 단말기 슬롯에 삽입 → '띠르릉' | 슬롯 진입 0.5초 유지 시 승인 |
| 현금 | 받은 지폐를 서랍에 넣음 → POS에 거스름돈 표시 → 동전(100·500)·지폐(1,000·5,000)을 집어 접시에 놓음 | 접시 합계 일치 시 완료, 과소·과다 시 '땡'+액수 표시 |

계산은 자동(받음−합계), 플레이어의 과제는 액수만큼 집어 놓는 조작이다.

## 6. 1일차 튜토리얼 — 조작 체인 6단계와 실패 회복

계산대 상단 월드스페이스 보드 + 음성 안내 6종(슬라이드 12 '튜토리얼·계산만, 손님 5명').

| 단계 | 지시 | 완료 조건 | 실패 회복 |
|---|---|---|---|
| T1 잡기 | 컵라면 집기 | 그립 Select | 15초 무행동 시 아웃라인 점멸 |
| T2 회전 | 바코드 찾기 | BarcodeFace가 플레이어 쪽 ±60°로 1초 | 2회 실패 후 림 라이트 힌트 |
| T3 스캔 | 빨간 구역에 대기 | '삑' 1회 | 20초 경과 시 스캐너 라이트 강조 |
| T4 봉투 | 봉투에 넣기 | Bagged 전환 | 낙하 상품 재회집 가능(처벌 없음) |
| T5 카드 | 카드 꽂기 | 승인음 | 카드 낙하 시 접시 위 리스폰 |
| T6 현금 | 5,000원 받아 3,500원 거슬러 주기 | 접시 금액 일치 | 2회 오류 시 동전 조합 표시, 3회 시 자동 완료(제안 추가 — 초심자 이탈 방지, 분석 §3-I) |

T6 후 같은 체인의 손님 5명이 순차 진입한다. 진행은 `TutorialStep` enum으로 저장해 이어하기한다.
