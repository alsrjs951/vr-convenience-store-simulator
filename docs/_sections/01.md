## 질의 미응답 기록 (솔직 기록, 2026-10-24)

2026-10-24에 6개 결정 질문(Q1 게이트 결과 / Q2 HMD 기종 / Q3 학습 인프라 / Q4 손님 표현 / Q5 상품 수 상한 / Q6 IP·라이선스)을 사용자에게 직접 물었으나 **응답이 없었다(미응답)**. 따라서 D1~D6은 종합 분석가의 권장안을 **기본값으로 채택한 것**이며 전항목 '기본값 — 사용자 확인 필요' 상태다(D1↔Q1~D6↔Q6). 원본은 `docs/제안서_객관분석.md` '사용자 질의응답'(109~153줄)이고, 아래 표의 '권고' 열이 그 섹션의 개선 권고(94~105줄)와 직접 연결된다. D7·D8은 질의 대상이 아닌 이번 문서화의 운영 결정이다.

## 갱신 규칙 — 답변이 바뀔 때 고칠 곳

**섹션 머리 각주 규약**: 02~09 각 섹션은 제목 바로 아래 인용줄로 결정 ID를 단다(예: `> 결정 근거: D3, D5 (기본값 — 사용자 확인 필요) — §01 결정 표`). 본문에는 채택값을 복제하지 않는다.

**갱신 절차(체크리스트)** — 사용자가 Q1~Q6의 답을 바꾸면:

1. 이 표의 해당 행 '채택값'을 고치고 기본값 표기를 `확정(YYYY-MM-DD)`로 바꾼다. **고칠 곳은 이 행 하나가 원본이다.**
2. `rg -n "D[1-8]" docs/_sections/ docs/제안서_객관분석.md` 로 해당 ID 참조 지점을 찾는다. 반영 지점 목록은 위 표 '반영 섹션' 열이 가리킨다.
3. 해당 섹션의 **머리 각주 결정 ID**와 파생 서술(일정 날짜·게이트 기준값·상품 수 등)만 수정한다.
4. `docs/제안서_객관분석.md` '사용자 질의응답'의 해당 Q·'반영 권고' 항목을 함께 갱신한다(그 문서의 갱신 규칙 111·153줄과 상호 대응).
5. D7·D8은 1단계 없이 수정하되 근거 문구는 남긴다(변경 이력).

**남는 열린 항목**: 권고 7의 상품당 시간 예산·권고 2의 구체 수치(스플랫 예산, 정제 시간 상한)는 질의 범위 밖이며 08(일정)·09(게이트 판정 기준)에서 수치로 정의한다(객관분석 152줄).
