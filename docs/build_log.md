# 빌드 점검 기록

주 2회(화·금 권장) 통합 빌드 점검 시 아래 표에 1줄씩 기록한다.

## 기록 규칙

- 각 점검마다 표에 1줄만 추가한다: `날짜 | 빌드# | 커밋 | fps | 차질 요약`.
- 커밋은 점검 시점의 `main` 커밋 해시(단축형)를 적는다.
- fps는 씬 로드·잡기·스캔·손님 1명·프레임 기록 확인 시 측정한 대표값을 적는다.
- 성능 수치의 원본·시계열은 `docs/perf/perf_log.csv`에 누적하고, 이 표에는 요약만 남긴다.
- 차질이 있으면 차기 점검 전에 수정하거나 GitHub Issues 버그 대장에 등록한다.
