# 사진 기준 매장 재배치 (2026-11-09)

> 사용자 요청: 한국 편의점 사진 한 장을 주고 "이미지와 같은 구조로 현실적인 편의점으로 구성하고 싶어."
>
> **상태: 씬 재빌드, 사진 시점 렌더 비교까지 끝났다.** Quest 2로는 보지 않았고 프레임도 재지 않았다. 검사 결과는 6장.

## 1. 사진과 게임 좌표 맞추기

계산대와 점원 자리는 그대로 두고 그 주변을 사진처럼 다시 놓았다. 결제 검사와 손 경로가 계산대의 월드 좌표에 묶여 있기 때문이다. 대신 사진의 시선 방향을 게임의 **−x** 방향으로 삼았다. 플레이어에게 월드 축은 의미가 없으므로, 계산대를 돌린 것과 결과가 같다.

| 사진 | 게임 |
|---|---|
| 앞쪽(사진 찍은 곳) | 가까운 벽 x = 4.5 |
| 안쪽 벽 (음료·주류 냉장고) | 먼 벽 x = −6 (방을 9m → 10.5m로 늘림) |
| 오른쪽 벽 (도시락·샌드위치·김밥 쇼케이스) | 앞벽 z = 5.5 |
| 왼쪽 (담배장, 유리 출입문) | z 낮은 쪽. 담배장은 계산대 뒤, 유리 전면은 z = −1.6 |

```text
                     [ 오픈 쇼케이스: 도시락 · 샌드위치 · 김밥 ]            앞벽 z 5.5
   ┌──────────────────────────────────────────────────────────────┐
   │[전자레인지·온수]                                              │
 먼│         [===== 곤돌라 A · B =====]▣ [아이스크림]               │
 벽│▣=거치대                                                 [진열대 C]
   │[냉장고 5대]                              줄2  줄1             │
   │    [곤돌라 D]▤     [  계 산 대  ][연장]                       │
 x │                       점원   폐기함                           │ 가까운 벽
-6 │                    [   담 배 장   ]              수거함 카트  │ x 4.5
   └──[ 유리 · 출입문 ]─┘(창고 공간)                  창고 입구 ───┘
                                                    (▤ = 곤돌라 D 끝 진열칸)
```

## 2. 바뀐 것

| 항목 | 내용 |
|---|---|
| 방 | x −6~4.5, z −2.5~5.5. 담배장 끝(x −1.75)부터 먼 벽까지는 유리 전면이 z −1.6에 있다 |
| 출입문 | 유리 전면 가운데(x −3.6, 폭 2.4m). 밖은 보도와 거리 그림. 타이틀 문도 이쪽으로 옮겼다 |
| 음료 냉장고 | 10대 → 5대, 먼 벽. 위에 남색 띠와 "음료 · 주류" |
| 쇼케이스 | 새 모델. 앞벽 8m(2m × 4칸), 5단, 단마다 조명, 기울어진 남색 머리판 |
| 담배장 | 새 모델. 계산대 뒤 3.55m, 조명 진열 2칸, 하부장, 조명 머리판, 세로 라이트박스 |
| 곤돌라 | 검은색으로 바꿈. A·B를 이어 3m 한 줄(x −3.4~−0.4), 계산대와 일직선에 곤돌라 D 추가(x −4.05~−2.55), D 끝에 얕은 진열칸 |
| 아이스크림 냉동고 | 새 모델. A·B 줄 끝 앞 (x 0.35~1.1, z 2.75~4.15) |
| 전자레인지·온수기 | 먼 벽, 냉장고와 쇼케이스 사이. 위에 포스터 2장 |
| 계산대 | 파란 상판, x 2.0까지 1m 연장. 연장부에 멤버십 안내판, 동전통, 계산기, 바구니, 봉투 걸이 |
| 천장 | 60cm 타일 + 가로로 도는 긴 조명 7줄, 에어컨 카세트, CCTV |
| 바닥 | 윤나는 회색 테라조 텍스처. 조명 반사를 그려 넣음 |
| 조명 | 따뜻한 색 → 사진처럼 중성 흰색 |
| 카테고리 표지 | "간편식" 박스 표지를 곤돌라 D 끝 위에. 천장 걸개 4개는 뺐다 |

손님 지점: 줄은 그대로, 구경 지점은 곤돌라 A·B 앞 2곳, 냉장고 앞(−4.5, 1.75), 쇼케이스 앞(2.1, 3.98). 문에서 계산대까지 5.86m.

## 3. 사진과 일부러 다르게 둔 것

- **브랜드:** 사진의 CU 이름·로고·보라/청록 색은 실제 상표다. 지금까지처럼 가상 "동아편의점"과 남색을 쓴다. 계산대 상판만 사진의 분위기에 맞춰 중간 파란색으로 했다(남색이면 검은 기기가 안 보인다).
- **상품(D9):** 상품을 폴리곤 모델이나 사진 판으로 대체하지 않는다. 그래서 사진만큼 빽빽하지 않다.
  - 쇼케이스: 내용물을 글자로 쓴 배송 트레이
  - 담배장: 번호와 색만 있는 칸(상표·포장 그림 없음)
  - 냉장고: 그대로 김 서린 필름
  - 곤돌라: 그대로 운송 상자 + 3DGS 납품 칸 5개
- **계산대 기기:** 핸드 스캐너와 모니터 1대가 아니라 지금의 고정형 스캐너와 화면 2대를 유지했다. 게임 규칙과 검사가 쓴다.

## 4. 게임에 미치는 영향

- 3일차 전자레인지·온수기가 계산대에서 멀어졌다. 걸어서 약 3.3초 → 약 5.7초(한 번 가는 데, 계산값). 3일차는 아직 플레이 검사가 없다.
- 입고 거치대 B가 안쪽으로 와서 카트에서의 거리가 달라졌다.
- 뒤쪽 통로(곤돌라 A·B와 쇼케이스 사이)는 전처럼 손님 경로에서 뺐다. 플레이어는 지나갈 수 있다.
- 출근 동선이 짧아졌다. 문으로 들어와 유리 전면을 따라 계산대 안쪽으로 바로 간다.

- 거쳐 온 문제:
