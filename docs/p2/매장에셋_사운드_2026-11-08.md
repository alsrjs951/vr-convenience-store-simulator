# 매장 외부 에셋 배치·사운드 생성 (P3-K1 방향·P3-K3 대행, 2026-11-08)

> 담당은 권도훈(P3-K1 매장 배치, P3-K3 사운드)이다. 이번에는 사용자 지시로 이민건 세션이 대신 진행했다. 사용자 지시는 두 가지였다. 매장은 "퀄리티 있는 외부 무료 에셋을 최대한 찾아서 배치", 사운드는 "필요한 사운드를 직접 생성". 주문 시나리오(P3-K2)는 `docs/p2/주문시나리오_2026-11-08.md`에 따로 정리했다.
>
> 검증 범위: 시뮬레이터(데스크톱 에디터)만 확인했다. Quest 2에서 보거나 들은 것은 없고, 측정도 하지 않았다(사용자 지시로 측정·HMD 검증은 미룸).

## 1. 결과 요약

- **매장 겉모습**
  - 바닥은 테라조 타일, 벽은 회벽 질감으로 바꿨다.
  - 천장이 새로 생겼다(발광 천장 패널 + 형광등 기구 5개).
  - 진열대는 밝은 회색 도장 금속, 입고 박스는 실제 골판지 면(화살표·주의 문구)이다.
  - 출입문 오른쪽 앞벽에 음료 냉장고 2대를 놓았다.
  - 계산대 뒤 왼쪽 벽에는 철제 창고 선반(위에 플라스틱 상자)과 손수레를 두었다.
- **소리**
  - 효과음 15종, 매장 환경음 1개(20초 반복), 손님 음성 8줄×남녀 2벌, 튜토리얼 안내 6줄, 입고 안내 4줄을 직접 만들었다.
  - 모두 게임에 연결했다. 그 전에는 코드가 만든 단순 톤만 있었고 음성은 없었다.
- **규칙은 그대로다.** 계산대·진열대·거치대·수거함·폐기함의 충돌 박스와 위치는 바꾸지 않았다. 새로 단단한 물체(충돌 있음)는 냉장고 2대와 창고 선반뿐이다. 둘 다 손님이 다니지 않고 자동 검사가 벽을 미는 경로도 아닌 곳에 두었다.
- 회귀 검사 결과는 6장에 있다.

### 2.1 무료로 쓸 만한 것을 못 찾은 것

양면 곤돌라, 계산대, 최신 POS·카드 단말기, 최신 전자레인지, 온수기, 장바구니, 유리 출입문은 사실적인 무료 모델을 못 찾았다(로그인 필요한 Sketchfab CC-BY 후보만 있음). 이것들은 지금 박스 모델 그대로다. Sketchfab 후보 목록은 7장에 있다. 받으려면 계정 로그인이 필요해서 사람이 직접 받아야 한다.

### 2.2 변환 (`scripts/windows/import_store_assets.py`)

```powershell
python -I scripts/windows/import_store_assets.py <다운로드_폴더> <프로젝트_폴더>
```

- URP Lit은 금속도를 R, 매끄러움을 A, 차폐(AO)를 G에서 읽는다. 그래서 재질마다 `<이름>_Mask.png`(R 금속도, G AO, A = 1 − 거칠기)를 만든다. 원본은 Poly Haven ARM, glTF 금속·거칠기, ambientCG 개별 맵이다.
- 골판지: Poly Haven 박스 텍스처는 45° 돌아간 아틀라스다. 화살표가 있는 옆면 하나를 돌려서 잘라냈다. 노멀 맵은 같은 각도로 벡터도 돌렸다. 입고 박스는 큐브 조각으로 만든 것이라 모델 대신 이 면 하나를 모든 면에 쓴다.
- 냉장고: Unity에 glTF 임포터 패키지가 없어서(패키지 추가 안 함) GLB를 OBJ로 바꿨다. 노드 변환은 그대로 적용했다. 안에 든 샴페인 병 모델(정점 11만 개, 라벨 포함)은 편의점 상품이 아니고 무거워서 뺐다. 결과는 정점 3,960개다.

### 2.3 배치 (`Assets/Editor/P3StoreDressing.cs`)

`P2StoreBuilder.Build`가 입고 집기를 만든 뒤, NavMesh를 굽기 전에 `P3StoreDressing.Dress`를 부른다. 냉장고와 선반이 NavMesh 굽기에 장애물로 들어가야 해서다.

- 표면: 기존 재질(`P2_Floor`, `P2_Wall`, `P2_Shelf`, `P2_Cardboard`)에 텍스처를 입혔다. 그 재질을 쓰는 모든 박스가 한꺼번에 바뀐다.
  - 바닥: 2m마다 반복, 타일 한 장 50cm.
  - 천장: 3.6m마다 반복, 패널 한 장 60cm.
- 천장은 아래를 향한 한 장짜리 면(Quad)이다. 그래서 위에서 내려다보는 검사 카메라에서는 보이지 않는다. 그림자는 드리우지 않아서 기존 방향광도 그대로 들어온다.
- 환경광: 발광 천장은 실제로 주변을 비추지 않는다(GI 굽기 없음). 그래서 실내용 3단 환경광(위 밝게, 아래 어둡게)으로 바꿨다. 3DGS 상품은 조명을 받지 않아서 바뀌지 않는다.
- 위치와 근거:
  - 냉장고 2대: x 2.7~4.43, z 4.5~5.44, 앞벽에 붙여 매장 안쪽을 향한다.
    - 자동 검사가 앞벽을 미는 곳(x ≈ 2)에서 0.5m 이상 떨어져 있다.
    - 손님 구경 지점 'Shelf B far'(3.6, 3.95)와는 0.55m 떨어져 있다.
  - 창고 선반: x −4.43~−3.93, z −1.75~−0.65, 계산대 뒤라 손님 바닥이 없는 곳이다. 자동 검사가 왼쪽 벽을 미는 줄(z ≈ −2.2)보다 0.25m 앞이다.
  - 손수레: 계산대 뒤 왼쪽 구석(x −4.42, z 0.15). 충돌은 없다.
  - 형광등 5개: 통로 위 4개, 계산대 뒤 1개.
- NavMesh 경로 길이(빌드 로그)는 바뀌기 전과 같다. 문에서 계산대 6.15m, 줄 1 5.59m, 줄 2 5.16m, 구경 지점 4곳 2.68~8.24m.
- 눈으로 보는 확인: `-executeMethod P3StoreDressing.RenderViews -p3-shots <폴더>`가 고정 시점 8장을 저장한다(에디터, 플레이 안 함). 이번 화면은 `docs/p2/evidence/store_dressing/`에 있다.

## 3. 사운드

### 3.1 만드는 법

```powershell
# 1) 음성 원본: Windows 한국어 TTS(Microsoft Heami)로 18줄
powershell -File scripts/windows/make_game_voices.ps1 -OutDir <tts_원본_폴더>
# 2) 효과음·환경음 합성 + 음성 다듬기(앞뒤 무음 자르기, −3dB 정규화, 남성 버전)
python scripts/windows/make_game_sounds.py <tts_원본_폴더> Assets/Audio/Generated
```

- 효과음은 numpy/scipy로 합성했다. 녹음이나 다운로드는 없다.
  - 사인파 화음: 스캔 '삑', 카드 승인, 배송 도착.
  - 비조화 배음 종소리: 도어벨, 호출벨.
  - 걸러낸 잡음: 테이프, 날개, 서랍, 놓기, 폐기, 박스 충격.
- 남성 음성: 한국어 TTS 목소리가 Heami(여성) 하나뿐이다. 그래서 WSOLA로 길이를 유지한 채 음높이를 0.68배로 낮췄다(기본 주파수 약 200Hz → 약 135Hz). 길이는 원본과 같다.
- 모든 파일은 최대 진폭 0.71 이하이고 클리핑 0이다. 파형·스펙트로그램도 한 번씩 봤다. 합계 6.5MB(효과음 44.1kHz, 음성 22.05kHz 모노).

| voice_intake_1~4 | 2일차 입고 안내 각 단계 시작 | 2D |

- 손님 목소리는 아바타 이름으로 고른다. `Female_…`이면 여성, 나머지는 남성.
- 줄은 앞 줄이 끝난 뒤 0.35초 쉬고 다음 줄이 나온다. 그 사이에 주문이 끝나면 남은 줄은 말하지 않는다.
- 코드:
  - `GameAudio`: 클립 필드와 `Say`, `NarrateTutorial`, `NarrateIntake`, 재생 횟수 기록. 클립이 비면 예전 생성 톤으로 대체한다.
  - `ScannerZone.BeepClip`.
  - `CustomerDirector`: 도착 대사, 재촉, 이탈, 도어벨.
  - `TutorialController`, `IntakeTutorial`: 안내 음성.
  - `IntakeDirector`: 배송음.
  - 클립 연결은 `P2StoreBuilder.AssignSounds`가 빌드 때 한다.
- 문구: 손님 대사는 구현 문서 6.1절의 종류를 따랐다(인사 2, 재촉 1, 이탈 1, 요청 4). 안내 음성은 안내판 문구를 말하기 좋게 줄였다. 입고 1단계는 상품 이름 대신 "첫 번째 박스"라고 말한다(박스 상품이 바뀌어도 맞도록).

### 3.3 주의

- **TTS 음성의 배포 조건은 확인하지 않았다.** Windows 내장 음성으로 만든 소리를 게임에 넣어 배포해도 되는지 Microsoft 약관을 보지 않았다. 학교 발표·시연에는 문제없을 것으로 보지만 추정이다. 공개 배포 전에는 확인하거나 사람 목소리로 바꾼다.
- 기계 음성이라 억양이 단조롭다. 남성 음성은 음높이를 바꾼 것이라 약간 인공적으로 들린다. 실제 소리는 데스크톱 스피커로도 들어 보지 않았고 파형·주파수로만 확인했다. Quest 2 헤드폰으로 들어 보는 것이 남은 확인이다.
