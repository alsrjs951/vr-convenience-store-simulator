# 매장 꾸미기 (2026-11-09)

> **상태: 씬 재빌드와 시뮬레이터 화면 확인까지 끝났다.** Quest 2로는 아직 보지 않았고, 프레임 측정도 하지 않았다.

## 1. 왜 했나

"첫 1분만 AAA처럼"을 목표로, 문이 열릴 때 보이는 매장을 먼저 고쳤다. 전에는 1일차 진열 상품 16개 말고는 냉장고 10대와 진열대가 비어 있었고, 조명이 균일해서 전시장처럼 보였다. 상품을 더 놓으려면 Gaussian 예산(지금 약 166만 개, 목표 150만, 상한 200만)을 넘으므로 권도훈의 병합본(P4-K1)이 필요하다. 이번에는 상품 없이 할 수 있는 것만 했다.

## 2. 만든 것

| 항목 | 내용 |
|---|---|
| 조명 | 환경광을 조금 따뜻하게, 직사광 약하게. 천장 패널도 약간 따뜻한 색 |
| 바닥 | 방 전체를 한 장으로 그린 텍스처(4096×3640). 타일에 천장 패널 아래 밝은 부분과 가구 아래 접촉 그림자가 그려져 있다 |
| 벽 | 바닥과 천장 쪽이 살짝 어두운 세로 그라데이션 |
| 가격표 | 곤돌라 앞뒤 4단, 진열대 C 4단. 상품이 놓이는 칸은 그 상품의 이름과 가격(신라면 1,000 등) |
| 빈 칸 | 닫힌 운송 상자(라벨: 스낵, 라면, 생활용품, 즉석식품). "입고 중인 매장"으로 읽힌다. 납품 칸(A-1, A-2, A-3, B-1, B-2)은 비워 두었다 |
| 곤돌라 | 칸 뒤판 색(크림, 하늘색), 끝면 안내판 4개(라면, 과자, 즉석, 생활) |
| 냉장고 | 김 서린 필름과 분류 머리글(탄산음료, 주스·이온, 커피, 우유·요거트, 생수), 행사 표시 |
| 걸개 간판 4개 | 1+1 행사, 시원한 음료, 신상품 입고, 2+1 골라 담기 |
| 포스터 | 1+1, 2+1, 알바 모집, 19세 미만 판매 금지, 택배·충전, 유통기한 매일 확인 |
| 바닥과 소품 | 입구 매트, 줄 서기 스티커 2개, 바구니 더미, 시계, 비상구 표시, CCTV, 소화기 |

## 3. 지킨 규칙

- **상품 사진·모델 없음(D9).** 글자와 색만 쓴다. 상자는 입고 박스와 같은 운송 상자다.
- **전부 불투명.** 월드 공간 UI는 3DGS 상품 위에 덮여 그려지므로(스플랫이 깊이를 안 쓴다), 손에 든 상품이 지나갈 수 있는 인쇄물은 불투명 면으로 만들었다.
- **충돌체 없음, NavMesh 굽기 뒤에 추가.** 손님 경로와 게임 규칙은 그대로다.

## 4. 코드 지도

- 배치와 조명: `Assets/Editor/P3StoreDetails.cs`, `P2StoreBuilder.BuildScene`의 마지막에서 호출
- 텍스처: `scripts/windows/make_store_signage.py` → `Assets/Art/Signage/`
- 정지 화면 확인: `-executeMethod P3StoreDressing.RenderViews -p3-shots <폴더>` (`02b_first_look`이 문 앞 시점)

## 5. 검증

| 항목 | 결과 |
|---|---|
| 씬 재빌드, 컴파일 | 통과. 렌더러 222개, 재질 45개 추가 |
| 시작 화면 흐름 `-p2-title-verify` | 72/72, 외부 마우스 입력 0 (손님 반응 추가 뒤 최종 장면 기준) |
| 화면 확인 | 문 열림, 입장, 계산대 시점을 플레이 캡처로(`evidence/title/editor/`), 고정 시점을 정지 화면으로(`evidence/store_details/`) 직접 봤다 |

하지 않은 것: Quest 2 확인, 72fps 측정, 1·2일차 회귀(충돌체와 규칙을 건드리지 않아 돌리지 않았다).

## 6. 남은 일

- Quest 2에서 볼 것: 가격표 글자가 읽히는지, 조명이 밝기에 맞는지, 72fps 여유. 그림자와 포스터가 더해진 뒤 렌더러가 222개 늘었다.
- 병합본이 오면 상자를 치우고 진짜 상품으로 채운다. 냉장고 필름도 같이 걷어 낸다.
