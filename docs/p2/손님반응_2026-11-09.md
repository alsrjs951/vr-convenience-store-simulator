# 손님 반응 (2026-11-09)

> **상태: 코드와 씬 재빌드, 시뮬레이터 검사까지 끝났다.** Quest 2로는 아직 보지 않았다. 눈 맞춤이 실제로 어떻게 느껴지는지는 착용해 봐야 안다.

## 1. 왜 했나

11/07 착용 소감의 "손님이 인위적"은 줄 서기로 일부만 나아졌다. 손님은 플레이어를 쳐다보지 않고, 말할 때 입이 움직이지 않았다. 사람을 상대하는 게임에서 가장 눈에 띄는 부분이다.

## 2. 만든 것 (`CustomerFace`)

| 상황 | 반응 |
|---|---|
| 계산대 앞 | 머리와 눈으로 플레이어를 바라본다. 가끔 계산대 위 물건을 내려다본다 |
| 줄에 서 있을 때 | 플레이어를 쳐다봤다가 시선을 돌렸다가 한다 |
| 걷거나 구경할 때 | 플레이어가 1.3m 안에 오면 돌아본다 |
| 항상 | 2~5.5초마다 눈을 깜빡인다 |
| 말할 때 | 음성의 실제 크기에 맞춰 턱이 움직인다 |
| 재촉할 때 (절반 시간) | 찌푸리고 살짝 고개를 젓는다 |
| 줄에서 45초 넘게 기다림 | 표정이 굳고 고개를 젓는다. 계산대에서 "한참 기다렸어요. 이거 계산해 주세요." |
| 빨리 끝냄 (팁) | 미소와 끄덕임 |
| 보통으로 끝냄 | 끄덕임 |
| 이탈 | 찌푸리고 크게 고개를 젓는다 |

Rocketbox 뼈대에 눈, 눈꺼풀, 턱, 입꼬리, 눈썹 뼈가 있어서 추가 에셋 없이 만들었다. 몸 동작 클립(대기, 걷기, 손 흔들기) 위에 `LateUpdate`로 얹는다. 축은 쉼 자세의 두 눈 위치로 구하므로 뼈대 방향에 기대지 않는다. 손님이 물건을 손으로 건네는 동작(IK)은 기획서대로 이번 범위 밖이다.

수치는 `CustomerFace.cs` 맨 위 상수에 있다.

## 3. 검증

| 검사 | 결과 |
|---|---|
| 얼굴 동작 `-p2-face-verify` | 8/8. 계산대 손님의 시선은 플레이어 눈에서 1.3° 벗어남 |
| 시작 화면 흐름 `-p2-title-verify` | 72/72. 손님 5명의 끄덕임·감사·미소 포함 |
| 2일차 아무것도 안 하기 `-p2-day2-idle` | 19/19. 재촉·이탈 경로 |
| 화면 | 얼굴 근접 사진으로 시선, 눈 감기, 입, 미소, 찌푸림을 직접 봤다(`docs/p2/evidence/customer_face/`) |

처음에는 눈꺼풀 뼈를 회전시켰더니 거의 안 감겼다. 눈꺼풀 뼈는 살 위에 있어서 이동으로 바꿨다.

하지 않은 것: Quest 2 확인, 1일차와 2일차 전체 회귀(손님 코드 중 대사 호출부만 바뀌었다), 새 음성 청취.
