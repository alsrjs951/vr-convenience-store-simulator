# 현금 결제: 금전출납기와 원화 (2026-11-10)

> 사용자 요청: 다른 편의점 게임의 포스기(열리는 서랍에 지폐·동전 칸이 있고, 화면에 받은 돈·돌려줄 돈·지금 금액이 뜨는 방식) 화면을 참고해, 우리 현금 결제를 현실적이고 품질 있게 고도화. 표기는 원화.
>
> **상태: 코드 수정, 씬 재빌드(조명 굽기 포함), 시뮬레이터 검사, 화면 확인까지 끝났다.** 1일차 230/230, 2일차 315/315(둘 다 외부 마우스 0). Quest 2에서는 보지 않았다. 동전 숫자가 읽히는지, 서랍까지 손이 편하게 닿는지, 칸에서 화폐를 집는 느낌은 헤드셋에서만 알 수 있다. IL2CPP 플레이어는 다시 빌드하지 않았다. 커밋하지 않았다.

## 1. 왜 바꿨나

- 현금 서랍이 계산대 위에 놓인 검은 판이었다. 열리지도 닫히지도 않았고, 칸 네 개에 화폐가 하나씩 놓여 있었다.
- 지폐와 동전이 색만 다른 납작한 상자였다. 금액은 그 위에 떠 있는 글자("5,000원")로 알렸다.
- 거스름돈에 쓸 수 있는 화폐가 100·500·1,000·5,000원 네 가지뿐이었다.
- POS에는 "받은 돈 5,000 · 거스름 1,500" 한 줄만 나왔다. 접시에 지금 얼마를 놓았는지는 알림 줄을 읽어야 알 수 있었다.
- 잘못 집은 화폐를 되돌릴 곳이 없어서 계산대에 굴러다녔다.

## 2. 바뀐 것

| | 전 | 후 |
|---|---|---|
| 서랍 | 계산대 위 검은 판(36 × 40cm), 항상 그대로 | POS 모니터 아래 금전출납기(40 × 41 × 10.5cm). 결제할 차례가 되면 서랍이 점원 쪽으로 30cm 튀어나오고, 결제가 끝나면 닫힌다 |
| 서랍 안 | 칸 4개, 화폐 1개씩 | 뒤쪽 지폐 4칸(5만·1만·5천·1천, 집게로 눌린 뭉치), 앞쪽 동전 4칸(500·100·50·10, 쌓인 더미). 동전 칸 앞턱에 금액 라벨 |
| 화폐 | 색 상자 + 떠 있는 글자 | 인쇄된 지폐(실제 크기, 권종 색, 큰 숫자)와 숫자가 찍힌 동전. 떠 있는 글자 없음 |
| 거스름돈 화폐 | 4종 | 8종. 집으면 그 자리에 다음 화폐가 놓인다 |
| 받은 지폐 | 판 위에서 놓으면 사라짐 | 열린 서랍 위에서 놓으면 그 권종 칸으로 미끄러져 들어감 |
| 잘못 집은 화폐 | 둘 곳 없음 | 열린 서랍 위에서 놓으면 제 칸으로 돌아감 |
| POS | 합계 아래 한 줄 | 합계 아래 세 칸: 받은 돈 / 거스름돈 / 접시에 놓은 돈. 놓은 돈 칸은 맞으면 초록, 넘치면 빨강 |
| 튜토리얼 화살표 | 서랍 전체에 "거스름돈 집기" | 다음에 집을 화폐 칸 위에 금액("1,000원"). 넘치면 접시에 "덜어내기" |
| 소리 | 서랍 '철컥' 하나 | 서랍 열림(걸쇠 + 종 + 구르는 소리), 닫힘, 동전 '짤랑', 지폐 '사락' |

규칙(스캔·봉투 전에는 결제 불가, 접시 금액이 0.5초 맞으면 완료, 과다는 바로·과소는 8초 멈추면 오류)과 주문 시나리오는 그대로다. 손님은 전과 같이 합계를 덮는 가장 작은 지폐 한 장을 낸다(`PaymentDesk.BillFor`).

## 3. 흐름

1. 손님이 계산대에 오면 손님 접시에 지폐가 놓인다.
2. 스캔과 봉투(3일차는 조리)가 끝나면 서랍이 열리고, POS 합계 아래에 세 칸이 나타난다. 아직 돈을 받지 않았으므로 세 칸 모두 "–"이다.
3. 지폐를 집어 열린 서랍 위에서 놓는다. 그 권종 칸으로 들어가고 POS에 받은 돈과 거스름돈이 뜬다.
4. 서랍 칸에서 화폐를 집어 거스름돈 접시에 놓는다. 놓은 금액이 POS의 셋째 칸에 바로 반영된다.
5. 금액이 맞은 채 0.5초 지나면 결제가 끝나고 서랍이 닫힌다.

서랍이 열리기 전에 지폐를 금전출납기 앞에 놓으면 '땡'과 함께 손님 접시로 돌아간다(전과 같은 규칙). 서랍은 사람이 닫지 않는다. 실제로는 점원이 밀어 닫지만, 손을 서랍 안으로 뻗는 동작과 미는 동작을 구분하기 어렵고 시간 제한이 있는 게임에서 단계가 하나 늘어나서 넣지 않았다.

튜토리얼의 현금 단계는 점장 대사("계산은 제가 찍어 놨어요")대로 시작부터 서랍이 열려 있고, POS 합계에 1,500원이 찍혀 있다.

## 4. 화폐 디자인

- **지폐는 자체 도안이다.** 한국은행권의 초상·문양·은행 이름은 쓰지 않았다. 실제 지폐에서 한눈에 구분되는 세 가지만 가져왔다: 크기(세로 68mm, 가로 136·142·148·154mm), 권종 색(천 원 파랑, 오천 원 주황, 만 원 초록, 오만 원 노랑), 금액 숫자. 초상 자리에는 기요셰 무늬를 넣었다.
- **동전은 실제의 1.25배다**(500원 33mm, 100원 30mm, 50원 27mm, 10원 22.5mm). 실제 크기에서는 헤드셋으로 숫자를 읽기 어렵다고 보고 키웠다. Quest 2에서 확인한 값은 아니다. 10원은 구리색, 50원은 약간 누런색, 100·500원은 흰 금속이다.
- 500원과 100원은 색이 같고 크기 차이가 3mm뿐이라, 동전 칸 앞턱에 라벨 프린터로 뽑은 것 같은 금액 라벨을 붙였다. 지폐 칸에는 붙이지 않았다(인쇄면으로 구분된다).
- 질감과 소리는 `scripts/windows/make_cash_assets.py`가 만든다(내려받는 것 없음). 글꼴은 Pretendard다.

```
python -I scripts/windows/make_cash_assets.py Assets/Art/Cash Assets/Audio/Generated
```

구현에서 알아 둘 것:

- **서랍 칸의 맨 위 화폐는 서랍의 자식이고 키네마틱이다.** 서랍과 함께 움직인다. 처음 잡히는 순간 일반 물리 소품이 된다. XRI는 놓을 때 잡기 전의 키네마틱 상태와 부모를 되돌리므로, `PaymentProp`이 `retainTransformParent`를 끄고 놓인 직후 키네마틱을 다시 푼다.
- **바닥에 떨어진 거스름돈은 사라진다.** 서랍에 다음 화폐가 있기 때문이다. 카드와 손님 지폐는 전처럼 접시로 돌아온다.
- **서랍에는 충돌체가 없다.** 몸체만 단단하다. 열린 서랍 위에서 놓은 화폐는 구역이 받아 칸으로 넣는다. 카드를 열린 서랍 위에서 놓으면 서랍을 통과해 바닥에 떨어졌다가 접시로 돌아온다.
- 열린 서랍은 계산대 가장자리 밖으로 약 11cm 나온다. 플레이어 몸은 서랍과 부딪히지 않는다.

현금 결제마다 새로 보는 검사(1일차 20개, 2일차 15개 추가):

- 결제할 차례에 서랍이 끝까지 열린다. 여덟 칸 모두 맨 위 화폐가 놓여 있고 POS 세 칸은 "–"이다
- 지폐를 넣으면 POS의 받은 돈·거스름돈이 맞고, 놓은 돈은 0이다
- 첫 화폐를 접시 위로 가져가면 POS의 놓은 돈이 그 금액이다
- 결제가 끝나면 서랍이 완전히 닫힌다
- 스캔 전에는 서랍이 닫혀 있고 칸에 화폐가 없으며 POS 세 칸이 없다(1일차 주문 2번)
- 과다 지급 뒤 5,000원을 서랍 위에서 놓으면 사라지고 그 칸이 다시 차 있다(1일차 주문 4번)
- 튜토리얼: POS 합계 1,500원·받은 돈 5,000·거스름돈 3,500, 화살표 이름이 "1,000원"

기존 검사(스캔 전 지폐 반환, 과소·과다 오류 횟수, 근무 종료 뒤 소품 0개 등)는 그대로 통과했다.

화면과 리포트: `docs/p2/evidence/cash_till/` (`still_*`은 정지 렌더, `play_*`은 검사 중 화면, `day1_report.json`, `day2_report.json`). 두 리포트는 같은 날 바구니를 없앤 뒤의 실행(1일차 242/242, 2일차 330/330, `계산대_상품놓기_2026-11-10.md`)으로 바꿔 넣었다. 현금 검사는 그 안에 그대로 있다.

거쳐 온 문제:

- **새 워크트리의 3DGS 에셋이 Git LFS 포인터였다.** 첫 씬 빌드와 첫 1일차 검사(230개 중 진열 스플랫 검사 1개 실패)는 상품 스플랫이 빈 상태였다. `git lfs checkout`으로 실파일을 채우고, 그동안 빌드가 바꾼 에셋을 되돌린 뒤 씬을 다시 빌드해 위 결과를 얻었다.
- 닫힌 서랍 위에서 내려다보면 앞판과 윗판 사이 3mm 틈으로 동전 칸 라벨이 보였다. 윗판을 앞판 위까지 내밀어 가렸다.
- 지폐 집게가 길어서 가운데 숫자를 가렸다. 끝만 누르도록 줄였다.
- 튜토리얼 이름표("현금 서랍")가 화폐 칸 화살표와 겹쳤다. 금전출납기 앞 모서리 위로 옮겼다.

하지 않은 것:

- Quest 2 확인 전부
- 3일차, 타이틀, 첫 1분, 자유 이동 검사. 카드(출근 카드 포함)는 같은 코드를 1·2일차 카드 결제가 지나간다
- 1일차 검사는 검사 스크립트에 화면 촬영 3장을 넣기 전에 돌렸다. 촬영을 넣은 뒤에는 2일차만 돌렸다
- IL2CPP 플레이어 재빌드와 플레이어 검사
- 소리를 귀로 듣기. 재생 횟수만 센다

## 7. 남은 일

- **서랍까지의 거리.** 금전출납기는 예전 서랍 자리(계산대 왼쪽 끝)에 있다. 시작 위치에서 열린 서랍 가운데까지 약 0.85m라 한 걸음 옮기거나 몸을 돌려야 한다. 봉투와 자리를 바꾸면 가까워지지만 봉투가 멀어진다. Quest 2에서 써 보고 정한다.
- **손님은 지폐 한 장만 낸다.** 여러 장이나 동전을 섞어 내는 손님은 없다. 지금 시나리오의 현금 주문은 합계 5,000원 이하이고 가격이 100원 단위라, 5만·1만 원 칸과 50·10원 칸은 거스름돈에 쓰이지 않는다(잘못 집을 수는 있다).
- **서랍을 손으로 닫지 않는다.** 3장에 이유를 적었다.
- 동전 1.25배, 라벨 크기, POS 세 칸의 글자 크기는 헤드셋에서 읽히는지 보고 조정한다.
- `docs/p2/evidence/day1/editor` 등 예전 증거 화면은 옛 서랍 그대로다. 다시 찍지 않았다.
- `Assets/Audio/Generated/sfx_drawer.wav`는 이제 서랍이 닫힐 때 쓴다.
