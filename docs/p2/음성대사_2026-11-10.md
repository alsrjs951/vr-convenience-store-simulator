# 음성 대사 다시 쓰기 (2026-11-10)

> 사용자 요청: "게임 내 음성과 그 내용을 더 퀄리티 있고 현실적인 대화처럼 개선하려고 한다. 목소리는 ElevenLabs를 쓸 계획이다. 일단 내용 자체를 더 현실적이고 자연스럽게 개선해 줘."
>
> **상태: 대사를 다시 썼고, ElevenLabs의 한국어 목소리로 음성 48개를 만들어 게임에 넣었다(4장).** 배역은 사용자가 그대로 쓰기로 했다(2026-11-10). 작업한 쪽은 길이·말 빠르기·음량을 수치로만 확인했고 소리는 듣지 못했다.

## 1. 무엇이 어색했나

- 점장의 말이 사람이 옆에서 하는 말이 아니라 설명서 문장이었다("~하세요"로 끝나는 지시문이 이어졌다).
- 손님 대사가 교과서 문장이었다("이거 계산해 주세요.", "감사합니다.").
- 손님 인사가 두 가지뿐이라 하루 내내 같은 말이 반복됐다.
- 3일차 안내가 틀려 있었다. 사진 기준 재배치(11/09) 때 전자레인지와 온수기가 점원 왼쪽의 냉장고 옆으로 옮겨졌는데, 음성과 화면 글자는 여전히 "오른쪽 벽"이라고 했다.

## 2. 어떻게 썼나

- **점장:** 첫날 온 알바를 옆에서 가르치는 40대 점장의 말투. 해요체, 짧은 문장, "~죠", "~면 돼요", "~봐요".
- **손님:** 편의점 계산대에서 실제로 하는 짧은 말("이거 계산이요.", "감사합니다, 수고하세요.").
- **길이:** 일하는 도중에 듣는 말이라 전보다 길어지지 않게 했다. 처음 쓴 안은 자연스러웠지만 전체가 33% 길어져서 군말을 덜어 냈다. 임시 음성 기준으로 전체 155초 → 163초이고, 늘어난 것은 새 인사 두 개(약 3초)와 몇몇 손님 대사다.
- **읽는 대로 적기:** 숫자와 기호는 소리 나는 대로 적었다("오천 원", "원 플러스 원").
- **게임과 맞추기:** 조작과 위치를 말하는 부분은 실제 게임과 맞췄다(가운뎃손가락 버튼, 오른쪽 단말기의 노란 칸, 왼쪽 서랍, 왼쪽 냉장고 옆 전자레인지).

## 3. 바뀐 것

- **대사 파일:** 모든 대사를 `Data/voice_lines.json` 한 곳에 모았다. 대사마다 누가, 언제, 어떤 느낌으로 말하는지가 같이 적혀 있다. 전에는 생성 스크립트 안에 글자만 있었다.
- **생성 스크립트:** `make_game_voices.ps1`(Windows TTS)과 `make_game_sounds.py`가 이 파일을 읽는다. ElevenLabs 스크립트도 같은 파일을 읽으면 된다.
- **손님 인사 2종 → 4종.** `P2StoreBuilder.Voice`가 네 개를 연결한다.
- **위치 안내 수정:** 3일차 안내판(`GameManager.OnOrderArrived`), POS 알림(`POSController`), 음성 안내 2개.
- **결말 화면의 인용문:** 점장의 새 결말 대사와 같은 말로 맞췄다(`GameManager`).

## 4. ElevenLabs 음성 (2026-11-10 적용)

게임의 음성 48개를 ElevenLabs의 한국어 원어민 목소리로 만들어 넣었다. 목소리는 소개 글을 보고 골랐고, 적용본과 다른 후보의 시험 음성을 보낸 뒤 **사용자가 이 배역 그대로 쓰기로 했다(2026-11-10).**

### 배역

| 역할 | 목소리 | 고른 이유(목소리 소개 글 기준) |
|---|---|---|
| 점장 | Amytah | 중년 여성, 서울말, 편하고 친근한 말투 |
| 손님 여 | Han | 젊은 여성, 대본 없이 말하는 듯한 일상 말투 |
| 손님 남 | Harry Kim | 성인 남성, 차분한 일상 말투 |

모델은 `eleven_v4`다. 세 목소리 모두 이 모델에서 한국어가 확인된 목소리로 올라 있다. 손님 대사는 여성·남성 목소리로 따로 만든다(전에는 여성 음성의 음높이를 낮춰 남성으로 썼다).

다른 후보의 시험 음성이 `capture/elevenlabs/audition_korean/`에 있다(저장소에는 올라가지 않는다). 점장: Stella, Park Hyun-mi, Seulki. 손님 여: Kanna, Hana Lee. 손님 남: Taehyung, Theo, Taemin. 고른 세 목소리는 `eleven_multilingual_v2`로도 만들어 두었다(`*_v2.mp3`). 목소리 ID는 `Data/voice_cast.json`에 적혀 있다.

### 거쳐 온 일

- 무료 요금제에서는 API로 음성 라이브러리의 목소리를 쓸 수 없었다(`402 paid_plan_required`). 쓸 수 있는 것은 영어 원어민인 기본 목소리 21개뿐이었다. 기본 목소리로 시험 음성 14개(`capture/elevenlabs/audition/`)를 만든 뒤, 사용자가 Starter 요금제로 바꿨다.
- Starter에서는 라이브러리 목소리를 계정에 추가하지 않고 ID만으로 쓸 수 있었다.
- 목소리마다 음량이 달라(점장 약 −16.5dB, 손님 −19~−22dB) 같은 평균 음량 −18dB로 맞췄다. 최대값을 맞추는 방식으로는 손님이 더 멀리서 말하는 것처럼 들린다.

### 사용량

Starter 월 40,000자 중 이번에 약 1,660자를 썼다(한국어 시험 408자, 전체 생성 1,238자, 연결 시험 12자). 무료일 때의 기본 목소리 시험 428자는 요금제를 바꾸며 초기화됐다. 전체를 처음부터 다시 만들면 1,292자다.

### 다시 만들기

```text
python -I scripts/windows/make_elevenlabs_voices.py Assets/Audio/Generated --dry-run     # 사용량만 계산
python -I scripts/windows/make_elevenlabs_voices.py Assets/Audio/Generated               # 전체
python -I scripts/windows/make_elevenlabs_voices.py Assets/Audio/Generated --only voice_greet_2 voice_thanks
python -I scripts/windows/make_elevenlabs_voices.py Assets/Audio/Generated --voice manager=<목소리 ID> --model eleven_multilingual_v2
```

- 대사는 `Data/voice_lines.json`, 목소리와 모델은 `Data/voice_cast.json`을 고친다.
- 받은 MP3는 `capture/elevenlabs/`에 보관한다. 같은 목소리·모델·대사는 다시 요청하지 않으므로 바뀐 것만 사용량이 든다.
- 파일 이름이 같아서 씬을 다시 빌드할 필요가 없다.
- API 키는 환경 변수 `ELEVENLABS_API_KEY`에서 읽는다. 사용자 수준 환경 변수는 이미 떠 있는 프로그램에는 보이지 않을 수 있어, 그럴 때는 실행하는 셸에서 한 번 읽어 넣는다.
- Windows TTS(`make_game_voices.ps1` + `make_game_sounds.py`)는 예비로 남겨 두었다. 이것을 다시 돌리면 ElevenLabs 음성이 덮어써진다.

### 확인하지 않은 것

- 음성 라이브러리 목소리의 사용 조건(출처 표기, 발표·배포 범위)과 요금제 조건
- 목소리 주인이 목소리를 내리면 일정 기간 뒤 새로 만들 수 없게 된다(이미 받은 파일은 그대로 쓸 수 있다)

## 5. 검증

| 대사 다시 쓰기 뒤(임시 TTS) | 씬 재빌드 통과, 첫 1분 72/72, 외부 마우스 0 |

- **청취.** 목소리가 역할에 맞는지, 억양이 자연스러운지, 대사를 잘못 읽은 곳이 없는지는 듣지 않고 알 수 없다
- 1·2·3일차 검사. 3일차 안내 문구는 화면으로 보지 않았다
- Quest 2, 플레이어 재빌드

## 6. 남은 일

- 대사를 잘못 읽은 곳이 있는지는 플레이하며 들어 봐야 안다. 고칠 때는 `Data/voice_lines.json`의 그 대사만 고치고 `--only`로 다시 만든다.
- 감사, 재촉 같은 손님 대사는 아직 한 가지씩이다. 인사처럼 여러 개로 늘리면 반복이 덜 느껴진다.
- 손님 목소리가 여성 1명, 남성 1명이라 손님 네 명이 같은 두 목소리로 말한다. 목소리를 늘리려면 `CustomerVoice`를 캐릭터별로 나눠야 한다.
