# 시연 모드: 처음 하는 사람을 위한 한 판 (2026-11-13)

> **상태: 에디터와 플레이어에서 XR 없이(XR Device Simulator) 확인했다. 헤드셋으로는 한 번도 켜 보지 않았다.** 워크트리 `aaa-game-development-strategy-6d77da`.

## 1. 왜

발표 뒤 교수가 직접 HMD를 쓰고 해 본다고 가정했다. 처음 하는 사람이 몇 분 안에, 설명 없이, 막히지 않고 한 판을 끝낼 수 있어야 한다. 지금까지의 시작 방법은 이 용도에 맞지 않았다.

- 타이틀부터: 문 앞에서 걸어 들어와 출근 카드를 찍고 수습 3일을 한다. 길다.
- 고정 1일차(`-hmd-perf`): 튜토리얼 뒤 손님 5명이고, 헤드셋이 방의 어디에 있든 그 자리에서 시작한다. 다음 사람을 위해 처음으로 돌리려면 프로그램을 껐다 켜야 했다.

## 2. 무엇이 되나

실행 인자 `-demo` 하나로 켠다.

| 순서 | 내용 |
|---|---|
| 시작 | 타이틀·걸어 들어오기·출근 카드 없이, 헤드셋이 있는 자리가 곧 계산대 안쪽 점원 자리가 된다(계산대를 바라보게 돌려 놓는다) |
| 튜토리얼 | 1일차 튜토리얼 그대로: 점장이 여섯 단계를 알려 준다(잡기, 바코드 찾기, 스캔, 봉투, 카드, 현금) |
| 손님 3명 | 1번 카드·봉투(상품 2개), 2번 현금(거스름돈 2,500원), 3번 현금·봉투(상품 2개, 거스름돈 1,300원). 3번은 2번 5초 뒤에 들어와 줄을 선다 |
| 끝 | 정산판(등급·점수·매출·팁·시재)과 그 아래 **"다시 하기"** 버튼 |

PC 키보드(게임 창이 앞에 있어야 한다):

| 키 | 하는 일 |
|---|---|
| **F5** | 언제든 처음부터 다시 시작한다(다음 사람이 헤드셋을 쓴 뒤 누른다). 매장 씬을 통째로 다시 불러온다 |
| **F6** | 다시 시작하지 않고, 지금 헤드셋이 있는 자리를 점원 자리로 다시 맞춘다 |

- 손님은 1일차 규칙을 따른다: 시간이 다 돼도 떠나지 않고, 줄 벌칙과 재촉이 없다. 시간 막대의 절반(50초) 전에 끝내면 팁이 나온다. 거스름돈은 틀릴 수 있다(`틀릴수있는_계산_2026-11-13.md`).
- 손님 수·순서·제한 시간 100초는 `Data/demo_scenarios.csv`에 있고 모두 **[제안]** 이다.
- `-demo`를 주지 않으면 아무것도 달라지지 않는다. F5·F6도 시연 모드에서만 듣는다.

## 3. 실행

헤드셋을 쓰고 Link 홈 화면이 보이는 상태에서 **PC에서** 실행한다. 헤드셋 라이브러리의 "VRStore"는 누르지 않는다.

```bash
C:/Projects/vr-convenience-store-simulator/.claude/worktrees/aaa-game-development-strategy-6d77da/Builds/Store/VRStore.exe -demo -screen-fullscreen 0 -screen-width 1920 -screen-height 1080 -logFile C:/Projects/vr-convenience-store-simulator/.claude/worktrees/aaa-game-development-strategy-6d77da/docs/p2/evidence/quest2/demo_1113.log
```

진행하는 사람의 순서: 프로그램을 켜 둔다 → 체험할 사람이 헤드셋을 쓰고 편한 자리에 선다 → PC에서 게임 창을 한 번 누르고 **F5** → 끝나면 다음 사람에게 넘기고 다시 **F5**.

`-hmd-perf`(성능 기록, 오른손 A로 화면 저장)와는 함께 쓰지 않는다: 기록 도구가 다시 시작을 넘기지 못한다(함께 켜 보지 않았다).

## 4. 어디를 고쳤나

- `GameManager`: `Demo`, `RunDemo`(자리 맞춤 → 1일차 → "다시 하기"), `Update`(F5·F6), `RestartDemo`(씬 다시 불러오기), `DemoScenario`.
- `StationLabel.Shown`: 이름표를 켜고 끄는 값이 씬을 넘어 남아서, 다시 시작할 때 켜 준다.
- `Data/demo_scenarios.csv`와 그 사본, `P2StoreBuilder`(빌드 때 가져오기, `InstallDemoScenarioInStore`로 씬을 다시 빌드하지 않고 연결).
- 검사 `-p2-demo-verify`(`P2DemoVerification.cs`): 다시 시작하면 검사 자신도 씬과 함께 사라지므로, 세 번에 걸쳐 돌며 앞의 결과를 넘겨받는다.

## 6. 확인하지 않은 것

- **헤드셋 전부.** 자리 맞춤이 실제 헤드셋에서 맞는지(키가 다른 사람, 방 가장자리에 선 사람), 씬을 다시 불러오는 몇 초 동안 헤드셋 화면이 어떻게 보이는지, 처음 하는 사람이 실제로 몇 분 걸리는지.
- 게임 창이 앞에 있지 않을 때 F5·F6가 듣는지. 헤드셋을 쓴 상태에서는 Link 창이 앞에 올 수 있다.
- 다시 시작을 여러 번(열 번 이상) 이어서 했을 때 느려지거나 메모리가 느는지. 세 번까지만 봤다.
- 손님 3명·100초가 처음 하는 사람에게 맞는 분량인지.

## 7. 남은 일

- 컨트롤러로 다시 시작하는 방법은 없다(체험자가 실수로 누를 수 있어 넣지 않았다). 진행자가 PC 앞에 있어야 한다.
- 정산판 문구가 1일차 것 그대로다("1일차 정산"). 시연용 문구로 바꿀지 정하지 않았다.
