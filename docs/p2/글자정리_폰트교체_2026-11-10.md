# 매장 글자 정리와 폰트 교체 (2026-11-10)

> 사용자 요청: "인게임에서 AI가 만든 것 같은 느낌이 난다. 편의점 안에 글이 너무 많아서 현실적으로 안 느껴진다. 현실적인 디자인을 원한다. 에셋을 돈 주고 살 생각은 없다."
>
> 진단에서 나온 6가지 중 1번(글자 걷어내기)과 3번(폰트 교체)을 했다. 나머지는 6장.

## 1. 왜 바꿨나

상품이 없는 자리를 전부 글자로 메워 놓은 상태였다. 간판 텍스처가 56장이었고, 냉장고 문 필름의 문구와 행사 원, 쇼케이스의 "김밥 · 도시락" 색 블록, 상자마다 붙은 라벨, 글자뿐인 포스터 11장이 시야 대부분을 차지했다. 실제 편의점에서 눈에 들어오는 것은 상품 포장이고, 글자는 간판과 작은 가격표, 법정 안내 정도다. 글자는 전부 Windows 기본 글꼴(맑은 고딕)이었다.

## 2. 글자를 남기는 기준

실제 매장에 있는 글자만 남긴다: 매장 이름, 구역 이름, 가격표, 법정 안내, 기기 화면. 상품이 없는 자리는 문구로 채우지 않고 비워 둔다.

## 3. 바뀐 것

| 항목 | 전 | 후 |
|---|---|---|
| 냉장고 문 필름 5장 | 분류 머리글 + 문구("톡 쏘는 시원함") + 1+1·2+1 원 | 글자 없는 김 서린 유리 한 종류(선반 그림자만 비친다) |
| 냉장고 위 "Icey Drinks" | 모델 원본의 영문 로고가 5대에 반복 | 글자 없는 조명 판으로 덮음(모델과 텍스처는 그대로) |

간판 텍스처는 56장에서 27장이 됐다(바닥·벽·천장·거리 그림 포함). 쓰지 않는 텍스처 31장과 재질 31개를 지웠다.

## 4. 폰트

- **Pretendard**(SIL OFL 1.1) Regular, Bold, ExtraBold 세 파일을 `Assets/Resources/Fonts/`에 넣었다. 출처는 공식 저장소 `github.com/orioncactus/pretendard` v1.3.9의 `packages/pretendard/dist/public/static/alternative/`(jsDelivr 경유, 2026-11-10 사용자 승인 후 받음). 라이선스 전문은 같은 폴더의 `Pretendard-LICENSE.txt`.
- UI(`WorldUi`)와 인쇄면(`make_store_signage.py`)이 같은 글꼴을 쓴다. 간판 제목은 ExtraBold, 그 밖의 굵은 글씨는 Bold, 본문은 Regular.
- 굵은 글씨는 `text.fontStyle = Bold` 대신 `WorldUi.Bold(text)`로 굵은 폰트 파일을 직접 쓴다(16곳). Regular를 두껍게 번지게 그리는 것을 피하려는 것이다. 매장 간판(`StoreSign`)은 `WorldUi.Heavy`.
- 폰트가 빌드에 들어가므로 Windows에 설치된 글꼴에 기대지 않는다. 파일이 없으면 경고를 남기고 전처럼 맑은 고딕을 쓴다.

쇼케이스는 글자를 빼고 보니 같은 상자로 가득 차 창고처럼 보였다. 맨 아래 단에는 상자를 두고 위 단은 30%만 남겼다. 나머지 단은 조명이 켜진 빈 선반이다.

## 6. 검증

모두 시뮬레이터와 에디터다. 이 워크트리에서 돌렸고, 그동안 다른 곳에서 `ns-train` 1개가 GPU를 쓰고 있었다.

| 항목 | 결과 |
|---|---|
| 씬 재빌드 `P2StoreBuilder.Build` | 통과. 세부 렌더러 428 → 245, 재질 38 |
| 고정 시점 렌더 18장 | 전후를 나란히 놓고 직접 봤다. 냉장고 위 로고가 옆에서도 안 보이는 것까지 확인 |
| 출근 흐름 `-p2-title-verify` | 75/75 통과. **단, 외부 마우스 입력이 1023.9 들어간 실행이라 이 프로젝트 기준으로는 무효다.** UI 화면을 찍는 용도로만 썼다 |
| UI 글자 | 타이틀, 설정, 손목시계, 주문 화면, 결과 카드, 근무 안내판에서 넘침이나 잘림 없음 |

하지 않은 것:

- Quest 2 확인, 프레임 측정, 플레이어 재빌드(`Builds/Store`는 예전 그대로)
- 1·2일차, 자유 이동, 첫 1분 검사. 충돌체와 규칙은 건드리지 않았다
- 보지 못한 UI: POS 품목 목록, 점장 말풍선과 튜토리얼 안내, 입고 상자 라벨, 정산 화면, 2·3일차 안내. 글꼴 폭이 달라졌으므로 일괄 테스트 때 넘침을 봐야 한다

## 7. 남은 일

진단의 나머지 네 가지다. 번호는 진단 때의 순서.

- **2. 상품으로 채우기:** 곤돌라가 운송 상자로 차 있어 아직 창고처럼 보인다. 첫 시야와 계산대 정면 진열대부터 스캔 상품을 놓는다(병합·LOD 뒤 동시 최대 약 87만, 목표 150만). 냉장고 유리 안에 스플랫을 넣으면 그리기 순서 문제가 날 수 있어 확인이 필요하다.
- **4. 재질과 조명:** 라이트맵과 반사 프로브가 없고 바닥 그림자는 그려 넣은 것이다. 바닥·벽·금속을 실사 PBR 재질로 되돌리고 조명을 굽는다.
- **5. 소품:** 계산대 기기, 전자레인지, 수거함이 둥근 상자다. 무료 모델(CC0, CC BY)로 바꾼다. 후보는 아직 찾지 않았다.
- **6. UI:** 떠 있는 남색 패널과 버튼의 생김새는 그대로다. 글꼴만 바뀌었다.
- 유리 밖 거리 그림이 만화처럼 보인다.
