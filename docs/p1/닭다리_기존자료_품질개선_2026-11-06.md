# 닭다리 기존 자료 품질 개선 — 10,000회

> 후속 검사: 기존 개봉면 사진의 추가 정합을 실제로 시험했으나, 다른 면의 반복 로고에 잘못 연결되어 채택하지 않았다. 기존 에셋의 6방향 검토와 제한은 [개봉면 사진 정합 시험](닭다리_개봉면사진_정합시험_2026-11-06.md) 참조. 사진 자료가 전혀 없는 것이 아니라, 정확한 위치 연결이 미확보인 상태다.

사용자가 실물을 현재 가지고 있지 않아, 보충 촬영 없이 기존 V01 자료로 진행했다.

## 결과

동일한 평가 이미지 7장을 비교했을 때 **전면·윗면 표현이 개선**됐다. 이전 3,000회 결과의 윗면 가시 형태가 크게 줄었다. 따라서 윗면을 즉시 재촬영하기보다 개선본으로 개발을 진행할 수 있다. 일부 가장자리 잔상, 반사 영역, 작은 인쇄의 오차는 남는다.

| 측정 | 3,000회 | 10,000회 |
|---|---:|---:|
| 상품 영역 PSNR 평균 | 20.59 dB | **26.59 dB** |
| 전체 장면 PSNR | 23.45 dB | 30.00 dB |
| 전체 장면 SSIM | 0.811 | 0.933 |
| 전체 장면 LPIPS | 0.215 | 0.098 |

상품 영역은 원본 이미지에서만 얻은 붉은 상자 볼록 외곽선 내부 픽셀로 고정했다. 두 실행의 GT 이미지가 픽셀 단위로 동일함을 검사했고, 7개 평가 시점 모두 상품 영역 PSNR이 증가했다. [측정 JSON](evidence/dakdari_refined/comparison.json), [원본/3,000회/10,000회 비교](evidence/dakdari_refined/same_view_comparison.jpg).

이 수치는 배경 분리 **이전 모델**의 재현 정확도다. 새로 촬영한 독립 데이터 검증, 바코드 실제 판독, 물리 크기 정확성, 바닥면 완성도 또는 VR 성능을 뜻하지 않는다. 반복 실험 평균이 아닌 각 실행의 결과 비교다.

## 학습·분리

- 기존 V01의 동일 74장, 학습 67/평가 7, COLMAP 모델 재사용.
- 초기 이어 학습은 `opacities.shape`와 Gaussian 수 불일치 오류로 종료됐다. 기존 체크포인트는 보존하고 새 실행 `trial-10000-fresh`에서 10,000회 학습했다.
- 최종 체크포인트 step 9999. 전체 장면 PLY 154,376개.
- 동일한 16시점 외곽선 투영 + 최대 연결 군집 필터로 배경을 분리: **50,854개**, **12,613,322 bytes**. PLY 모든 속성 finite 확인.
- [배경 분리 기록](evidence/dakdari_refined/isolation.json), [전체 장면 평가](evidence/dakdari_refined/full_scene_eval.json).
- 이전 3,000회 에셋·씬과 기존 Windows 실행 파일은 유지했다.

- 새 Unity 씬: `Assets/Scenes/DakdariRefined.unity`

- 분리 스크립트: `scripts/windows/isolate_dakdari.py`; 이번 실행 로그 `session_v01/isolation-10000.log`.

## 현재 진행 가능 / 미확인

개선본으로 시뮬레이터의 상품 배치·잡기·회전·바코드 면 방향 검사 등 개발을 진행할 수 있다. 바코드 게임 로직의 트리거와 실제 이미지 바코드 판독은 별개이며, 후자는 아직 검증하지 않았다.

실물이 생기면 바닥면 촬영과 가로·세로·두께 실측을 우선한다. 현재는 실제 치수를 임의로 넣거나 바닥면을 합성하지 않았다. 윗면 재촬영은 개선본을 실제 사용 거리에서 확인한 뒤 결정해도 된다. 기존 자료를 더 학습한 것만으로 관측되지 않은 면을 확보한 것은 아니다.
